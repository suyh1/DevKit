## ls

列出目录内容，可查看隐藏文件、权限、大小和修改时间。

以长格式列出当前目录的文件，包含隐藏文件，并以易读单位显示大小。

```sh
ls -lah
```

按修改时间从新到旧列出下载目录。

```sh
ls -lt ~/Downloads
```

## pwd

显示当前工作目录的路径。

显示当前目录的路径。

```sh
pwd
```

显示当前目录的物理路径（解析所有符号链接）。

```sh
pwd -P
```

显示帮助。

```sh
pwd --help
```

## cd

切换当前 Shell 的工作目录。

进入上一级目录。

```sh
cd ..
```

返回刚才所在的目录。

```sh
cd -
```

## tree

以树的形式显示当前目录的内容。

显示深度达到 “级数” 级的文件和目录（其中 1 表示当前目录）。

```sh
tree -L 级数
```

只显示目录。

```sh
tree -d
```

同时显示隐藏文件并开启彩色输出。

```sh
tree -a -C
```

打印没有缩进行的树，显示完整路径（使用`-N`不转义空格和特殊字符）。

```sh
tree -i -f
```

以可读格式打印每个文件节点的大小，目录显示其累积大小（类似在`du`命令中所示）。

```sh
tree -s -h --du
```

## exa

`ls` 的现代替代品（列出目录内容）。 注意：`exa` 已不再维护。请改用 `eza`。

每行列出一个文件。

```sh
exa -1
```

列出所有文件，包括隐藏文件。

```sh
exa -a
```

以长格式列出所有文件（包含权限、所有者、大小和修改日期）。

```sh
exa -l -a
```

列出文件，最大的排在最上面。

```sh
exa -r -s size
```

显示文件树，深度为三层。

```sh
exa -l -T -L 3
```

## eza

基于 `exa` 构建的现代化、持续维护的 `ls` 替代品。

每行列出一个文件。

```sh
eza -1
```

列出所有文件，包括隐藏文件。

```sh
eza -a
```

以长格式列出所有文件（包含权限、所有者、大小和修改日期）。

```sh
eza -al
```

列出文件，最大的排在最上面。

```sh
eza -r -s size
```

显示文件树，深度为三层。

```sh
eza -lT -L 3
```

## basename

移除一个路径的目录部分字符。

仅显示文件名。

```sh
basename 路径/到/文件
```

显示路径字符最右边表示目录的字符。

```sh
basename 路径/到/目录/
```

展示无后缀的文件名称。

```sh
basename 路径/到/文件 后缀
```

## dirname

提取路径的目录部分。

返回 /var/log。

```sh
dirname /var/log/app.log
```

## realpath

解析文件的绝对路径及路径中的符号链接。

显示当前目录的实际路径。

```sh
realpath .
```

## readlink

读取符号链接指向的目标。

解析链接及其中间目录，输出最终路径。

```sh
readlink -f ./current
```

## stat

查看文件的类型、权限、时间戳及 inode 信息。

用格式串输出文件名和字节数。

```sh
stat -c '%n %s' report.txt
```

## file

确定文件类型。

提供指定文件类型的描述，对于没有文件扩展名的文件可以正常工作。

```sh
file 文件名
```

查看压缩文件并确定其中的文件类型。

```sh
file -z xxx.zip
```

允许文件与特殊文件或设备文件一起使用。

```sh
file -s 文件名
```

不要在第一个文件类型匹配时停止；继续执行直到文件结束。

```sh
file -k 文件名
```

确定文件的 MIME 编码类型。

```sh
file -i 文件名
```

## touch

创建文件并设置访问/修改时间。

创建指定的文件。

```sh
touch 路径/到/文件1 路径/到/文件2 ...
```

将文件的访问(a)或修改时间(m)设置为当前时间，如果文件不存在则不创建(-c)。

```sh
touch -c -a 路径/到/文件1 路径/到/文件2 ...
```

将文件时间(-t)设置为指定值，如果文件不存在则不创建(-c)。

```sh
touch -c -t YYYYMMDDHHMM.SS 路径/到/文件1 路径/到/文件2 ...
```

将文件时间设置为另一文件(-r,即文件 3)的时间，如果文件不存在则不创建(-c)。

```sh
touch -c -r 路径/到/文件3 路径/到/文件1 路径/到/文件2 ...
```

## mkdir

创建目录并设置其权限。

创建特定目录。

```sh
mkdir 路径/到/目录1 路径/到/目录2 ...
```

根据需要创建特定目录及其父目录。

```sh
mkdir -p 路径/到/目录1 路径/到/目录2 ...
```

创建具有特定权限的目录。

```sh
mkdir -m u=rwx,g=rw,o=r 路径/到/目录1 路径/到/目录2 ...
```

## rmdir

删除一个目录。

删除空目录，使用 `rm -r` 删除非空目录。

```sh
rmdir 路径/到/目录
```

删除目标及其父目录（对嵌套的目录有用）。

```sh
rmdir -p 路径/到/目录
```

## mktemp

创建名称唯一的临时文件或目录。

创建临时目录并显示路径。

```sh
mktemp -d
```

## cp

复制文件和目录。

将文件复制到另一个位置。

```sh
cp 路径/到/源_文件.ext 路径/到/目标文件.ext
```

将文件复制到另一个文件夹，并保留原来的文件名。

```sh
cp 路径/到/源文件.ext 路径/到/目标的目录
```

以递归方式将文件夹内的内容复制到另一个位置（如果目标文件夹存在，则将此文件夹复制到目标文件夹中）。

```sh
cp -r 路径/到/源目录 路径/到/目标目录
```

以详细模式递归复制目录（在复制文件时显示文件信息）。

```sh
cp -vr 路径/到/源目录 路径/到/目标目录
```

一次将多个文件复制到一个目录。

```sh
cp -t 路径/到/目标_目录 路径/到/文件1 路径/到/文件2 ...
```

## mv

移动或重命名文件或目录。

重命名文件或目录，当目标不是一个已存在的目录时。

```sh
mv 路径/到/源 路径/到/目标
```

将文件或目录移动到已存在的目录中。

```sh
mv 路径/到/源 路径/到/已存在的目录
```

将多个文件移动到已存在的目录中，并保持文件名不变。

```sh
mv 路径/到/源1 路径/到/源2 ... 路径/到/已存在的目录
```

覆盖现有文件前无需确认。

```sh
mv -f 路径/到/源 路径/到/目标
```

无论是否有文件权限，覆盖现有文件前均需要确认。

```sh
mv -i 路径/到/源 路径/到/目标
```

## rm

移除文件或目录。

移除一个文件，每次删除前询问。

```sh
rm -i -- 草稿.txt
```

## ln

创建指向文件和目录的链接。

创建指向文件或目录的符号链接。

```sh
ln -s /路径/到/文件或目录 路径/到/符号链接
```

创建相对于链接所在位置的符号链接。

```sh
ln -s 路径/到/文件或目录 路径/到/符号链接
```

覆盖现有的符号链接以指向其他文件。

```sh
ln -sf /路径/到/新文件 路径/到/符号链接
```

创建文件的硬链接。

```sh
ln /路径/到/文件 路径/到/硬链接
```

## install

复制文件并设置属性。 将文件（通常是可执行文件）复制到系统位置，如 `/usr/local/bin`，并赋予它们适当的权限或所有权。

复制文件到目标目录。

```sh
install 路径/到/源文件1 路径/到/源文件2 ... 路径/到/目标目录
```

复制文件到目标目录，并设置其所有权。

```sh
install -o 用户 路径/到/源文件1 路径/到/源文件2 ... 路径/到/目标目录
```

复制文件到目标目录，并设置其所属组。

```sh
install -g 用户组 路径/到/源文件1 路径/到/源文件2 ... 路径/到/目标目录
```

复制文件到目标目录，并设置其权限。

```sh
install -m +x 路径/到/源文件1 路径/到/源文件2 ... 路径/到/目标目录
```

复制文件到目标目录，保留访问时间和修改时间。

```sh
install -p 路径/到/源文件1 路径/到/源文件2 ... 路径/到/目标目录
```

## unlink

从文件系统中删除对文件的链接。 如果链接是文件的最后一个，文件内容将丢失。

如果是最后一个链接，则删除指定的文件。

```sh
unlink 路径/到/文件
```

## namei

逐层检查路径的每个组成部分。

查看各级目录的权限与所有者。

```sh
namei -l /var/log
```

## pathchk

检查路径是否符合名称和长度限制。

按可移植文件名规则检查路径。

```sh
pathchk -p reports/result.txt
```

## dos2unix

将 DOS 样式的行尾更改为 Unix 样式。 用 LF 替换 CRLF。

更改文件的行尾。

```sh
dos2unix 文件名
```

使用 Unix 样式的行尾创建副本。

```sh
dos2unix -n 文件名 文件名
```

## unix2dos

将 Unix 样式的行尾更改为 DOS 样式。 用 CRLF 替换 LF。

更改文件的行尾。

```sh
unix2dos 文件名
```

使用 DOS 样式的行尾创建副本。

```sh
unix2dos -n 文件名 新文件名
```
