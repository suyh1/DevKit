## tar

归档实用程序。 通常与压缩方法结合使用，例如 `gzip` 或 `bzip2`。

创建存档并将其写入文件。

```sh
tar cf 目标文件.tar 路径/到/文件1 路径/到/文件2 ...
```

创建一个 gzip 压缩文件并将其写入文件。

```sh
tar czf 目标文件.tar.gz 路径/到/文件1 路径/到/文件2 ...
```

使用相对路径从目录创建一个 gzip 压缩文件。

```sh
tar czf 目标文件.tar.gz -C 路径/到/目录 .
```

详细地将（压缩的）存档文件提取到当前目录中。

```sh
tar xvf 源文件.tar.ext
```

将（压缩的）存档文件解压缩到目标目录中。

```sh
tar xf 源文件.tar.ext -C 目标目录
```

## gzip

使用 gzip 格式压缩文件。

输出压缩文件并保留原文。

```sh
gzip -k report.txt
```

## gunzip

解压 gzip 文件。

将解压结果写到标准输出，保留压缩文件。

```sh
gunzip -c archive.txt.gz
```

## zcat

解压 gzip 文件并输出到终端或管道。

分页阅读压缩日志。

```sh
zcat app.log.gz | less
```

## zless

查看 `gzip` 和 `xz` 压缩文件。

使用 `less` 分页查看一个 `gzip` 压缩文件。

```sh
zless 文件.txt.gz
```

## zgrep

在压缩文件中从文件中 grep 文本模式（等价于 `grep -Z`）。

在压缩文件中 grep 一个模式（区分大小写）。

```sh
zgrep 模式 路径/到/压缩/文件
```

在压缩文件中 grep 一个模式（不区分大小写）。

```sh
zgrep -i 模式 路径/到/压缩/文件
```

输出包含匹配模式的行数。

```sh
zgrep -c 模式 路径/到/压缩/文件
```

显示不包含该模式的行（反转搜索功能）。

```sh
zgrep -v 模式 路径/到/压缩/文件
```

在压缩文件中为多个模式执行 grep。

```sh
zgrep -e "模式_1" -e "模式_2" 路径/到/压缩/文件
```

## bzip2

用 bzip2 格式压缩文件。

压缩一个文件并保留原文件。

```sh
bzip2 -k report.txt
```

## bunzip2

解压 bzip2 文件。

解压并保留原压缩包。

```sh
bunzip2 -k report.txt.bz2
```

## xz

解压缩 XZ 和 LZMA 文件。

使用 xz 压缩文件。

```sh
xz 路径/到/文件
```

解压 XZ 文件。

```sh
xz -d 路径/到/文件.xz
```

使用 lzma 压缩文件。

```sh
xz -F lzma 路径/到/文件
```

解压 LZMA 文件。

```sh
xz -d -F lzma 路径/到/文件.lzma
```

解压文件并输出到 `stdout`（暗示 `--keep`）。

```sh
xz -d -c 路径/到/文件.xz
```

## unxz

解压 xz 文件。

将解压结果输出到标准输出。

```sh
unxz -c report.txt.xz
```

## zstd

使用 Zstandard 压缩来压缩 / 解压文件。

将一个文件压缩到一个 `.zst` 后缀的压缩文件中。

```sh
zstd file
```

解压缩一个文件。

```sh
zstd --decompress file.zst
```

将文件解压缩到标准输出（`stdout`）。

```sh
zstd --decompress --stdout file.zst
```

使用指定的压缩等级来压缩一个文件.0 = 最差，19 = 最好（默认等级是 3）。

```sh
zstd -level file
```

使用更多内存（解压或压缩时）来得到更高的压缩比。

```sh
zstd --ultra -level file
```

## zip

将文件打包并压缩（存档）为 zip 文件。

将文件/目录添加到指定存档中。

```sh
zip -r 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...
```

从指定存档中删除文件/目录。

```sh
zip -d 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...
```

存档文件/目录，排除指定的文件/目录。

```sh
zip -r 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ... -x 路径/到/排除的文件或目录
```

以指定的压缩级别存档文件/目录（`0` - 最低，`9` - 最高）。

```sh
zip -r -0..9 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...
```

创建一个加密的存档。

```sh
zip -re 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...
```

## unzip

从 Zip 压缩包中提取文件或目录。

将指定压缩包中的所有文件和目录提取到当前目录下。

```sh
unzip 路径/到/压缩文件1.zip 路径/到/压缩文件2.zip ...
```

将压缩包中的所有文件和目录提取到指定目录下。

```sh
unzip 路径/到/压缩文件1.zip 路径/到/压缩文件2.zip ... -d 路径/到/输出目录
```

从压缩包中提取文件或目录到 `stdout`（标准输出），并附带文件名。

```sh
unzip -c 路径/到/压缩文件1.zip 路径/到/压缩文件2.zip ...
```

提取在 Windows 上创建的压缩包，其中包含非 ASCII（例如中文或日文字符）命名的文件。

```sh
unzip -O gbk 路径/到/压缩文件1.zip 路径/到/压缩文件2.zip ...
```

在不进行解压缩的情况下，列出指定压缩包中的内容。

```sh
unzip -l 路径/到/压缩文件.zip
```

## zipinfo

列出 ZIP 内的文件、压缩方式和大小。

只输出归档中的文件名。

```sh
zipinfo -1 data.zip
```

## zipgrep

在 Zip 压缩档案中的文件中使用扩展正则表达式查找模式（支持 `?`、`+`、`{}`、`()` 和 `|`）。

在 Zip 压缩档案中搜索一个模式。

```sh
zipgrep "搜索模式" 路径/到/文件.zip
```

打印匹配的文件名和行号。

```sh
zipgrep -H -n "搜索模式" 路径/到/文件.zip
```

搜索与模式不匹配的行。

```sh
zipgrep -v "搜索模式" 路径/到/文件.zip
```

指定在 Zip 压缩档案中要搜索的文件。

```sh
zipgrep "搜索模式" 路径/到/文件.zip 要搜索的文件1 要搜索的文件2 ...
```

排除在 Zip 压缩档案中要搜索的文件。

```sh
zipgrep "搜索模式" 路径/到/文件.zip -x 要排除的文件1 要排除的文件2 ...
```

## 7z

一个高压缩率的文件归档器。

归档一个文件或目录。

```sh
7z a 归档文件.7z 文件或目录
```

对已存在的归档文件加密（包括文件名）。

```sh
7z a 加密文件.7z -p密码 -mhe=on 归档文件.7z
```

提取一个已存在的 7z 文件，并保持原来的目录结构。

```sh
7z x 归档文件.7z
```

提取一个归档文件到指定的输出目录。

```sh
7z x 归档文件.7z -o输出目录
```

提取一个归档文件到标准输出。

```sh
7z x 归档文件.7z -so
```

## 7za

一个高压缩率的文件归档器。 类似于 `7z`，支持的文档类型更少但跨平台。

归档一个文件或目录。

```sh
7za a 归档文件.7z 文件或目录
```

加密一个已存在的归档文件（包括文件名）。

```sh
7za a 加密文件.7z -p密码 -mhe=on 归档文件.7z
```

提取一个已存在的 7z 文件，并保持原来的目录结构。

```sh
7za x 归档文件.7z
```

提取一个归档文件到指定目录。

```sh
7za x 归档文件.7z -o输出目录
```

提取一个归档文件到标准输出。

```sh
7za x 归档文件.7z -so
```

## unrar

提取 RAR 压缩档案。

提取文件并保留原始目录结构。

```sh
unrar x 路径/到/压缩包.rar
```

将文件提取到指定路径，并保留原始目录结构。

```sh
unrar x 路径/到/压缩包.rar 路径/到/解压目录
```

提取文件到当前目录，但不保留档案中的目录结构。

```sh
unrar e 路径/到/压缩包.rar
```

测试档案内每个文件的完整性。

```sh
unrar t 路径/到/压缩包.rar
```

列出档案内的文件并不解压。

```sh
unrar l 路径/到/压缩包.rar
```

## unar

从归档文件中提取内容。

提取一个归档文件到当前目录。

```sh
unar 归档文件
```

提取一个归档文件到指定目录。

```sh
unar -o 路径/到/目录 归档文件
```

如果要提取的文件已经存在，则总是覆盖。

```sh
unar -f 归档文件
```

如果要提取的文件已经存在，则总是重命名。

```sh
unar -r 归档文件
```

如果要提取的文件已经存在，则总是跳过。

```sh
unar -s 归档文件
```

## cpio

将文件复制到归档中或从归档中复制出来。 支持以下归档格式：cpio 自定义二进制格式、旧 ASCII、新 ASCII、crc、HPUX 二进制格式、HPUX 旧 ASCII、旧 tar 以及 POSIX.1 tar。

从标准输入读取文件名列表，并以 cpio 二进制格式将文件写入归档（copy-[o]ut 模式）。

```sh
echo "路径/到/文件1 路径/到/文件2 ..." | cpio -o >目标文件.cpio
```

递归复制目录中的所有文件和子目录并写入归档（copy-[o]ut 模式），同时显示详细输出。

```sh
find 路径/到/目录 | cpio -ov >目标文件.cpio
```

从归档中提取所有文件（copy-[i]n 模式），按需创建目录，同时显示详细输出。

```sh
cpio <源文件.cpio -idv
```

## ar

创建，修改，提取库文件（`.a`, `.so`, `.o`）。

从库文件中提取全部成员。

```sh
ar x a 文件
```

列出库文件中的成员。

```sh
ar t a 文件
```

替换或添加文件到库文件。

```sh
ar r 要被添加内容的 a 文件 o 文件1 o 文件2 o 文件3 ...
```

插入对象文件索引（相当于使用`ranlib`）。

```sh
ar s a 文件
```

使用文件和附带的目标文件索引创建存档。

```sh
ar rs a 文件 o 文件1 o 文件2 ...
```
