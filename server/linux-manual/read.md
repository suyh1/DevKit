## cat

打印和连接文件。

将文件内容打印到 `stdout`。

```sh
cat 路径/到/文件
```

将多个文件连接到一个输出文件。

```sh
cat 路径/到/文件1 路径/到/文件2 ... >路径/到/输出文件
```

将多个文件附加到输出文件。

```sh
cat 路径/到/文件1 路径/到/文件2 ... >>路径/到/输出文件
```

将 `stdin` 写入文件。

```sh
cat - >路径/到/文件
```

显示带有行号的所有行。

```sh
cat -n 路径/到/文件
```

## tac

按行逆序输出文件。

从最后一行开始查看记录。

```sh
tac records.txt
```

## less

打开一个文件进行交互式阅读，允许滚动和搜索。

打开一个文件。

```sh
less 路径/到/文件
```

向下/向上翻页。

```sh
<Space>
```

转到文件末尾/开头。

```sh
<G>
```

向前搜索字符串（按 `<n>`/`<N>` 转到下一个/上一个匹配项）。

```sh
</>关键字
```

向后搜索字符串（按 `<n>`/`<N>` 转到下一个/上一个匹配项）。

```sh
<?>关键字
```

## more

以交互方式显示文件，允许滚动和搜索。

打开文件。

```sh
more 路径/到/文件
```

显示特定行。

```sh
more +行号 路径/到/文件
```

转到下一页。

```sh
<空格键>
```

搜索字符串（按 `<n>` 转到下一个匹配项）。

```sh
</>关键字<Enter>
```

退出。

```sh
<q>
```

## head

输出文件的开头部分的内容。

输出文件的前几行。

```sh
head -n 数目 路径/到/文件
```

输出文件的前几个字节。

```sh
head -c 数目 路径/到/文件
```

输出文件除最后几行之外的所有内容。

```sh
head -n -数目 路径/到/文件
```

输出文件除最后几个字节之外的所有内容。

```sh
head -c -数目 路径/到/文件
```

## tail

显示文件的最后一部分。

显示文件中最后 n 行。

```sh
tail -n n 路径/到/文件
```

从特定行号开始打印文件后续内容。

```sh
tail -n +行号 路径/到/文件
```

从给定文件末尾打印特定字节数量的内容。

```sh
tail -n 字节数 路径/到/文件
```

打印给定文件的最后几行并保持读取直到 `<Ctrl c>`。

```sh
tail -f 路径/到/文件
```

保持读取文件直到 `<Ctrl c>`，即使文件无法访问。

```sh
tail -F 路径/到/文件
```

## bat

可以打印并且合并文件的命令。 `cat` 的复制品，外加语法高亮和 Git 集成。

使用美化样式打印一个或多个文件的内容到 `stdout`。

```sh
bat 路径/到/文件1 路径/到/文件2 ...
```

将多个文件连接成一个目标文件。

```sh
bat 路径/到/文件1 路径/到/文件2 ... >路径/到/目标文件
```

移除修饰并禁用分页。

```sh
bat -pp 路径/到/文件
```

使用不同的背景颜色高亮显示特定行或一行范围。

```sh
bat -H 10 路径/到/文件
```

显示不可打印字符，如空格、制表符或换行。

```sh
bat -A 路径/到/文件
```

## nl

为文本行编号。

为包括空行在内的每一行添加行号。

```sh
nl -ba notes.txt
```

## wc

计数行、单词或字节。

计数文件中的行数。

```sh
wc -l 路径/到/文件
```

计数文件中的单词数。

```sh
wc -w 路径/到/文件
```

计数文件中的字节数。

```sh
wc -c 路径/到/文件
```

计数文件中的字符数（考虑所有多字节的字符）。

```sh
wc -m 路径/到/文件
```

使用 `stdin`，按顺序计数行、单词和字节。

```sh
find . | wc
```

## od

以指定进制显示文件字节。

用十六进制查看前 32 字节。

```sh
od -An -tx1 -N32 sample.bin
```

## xxd

在二进制和十六进制表示之间转换。

逐字节显示文件开头。

```sh
xxd -g 1 -l 64 sample.bin
```

## hexdump

一个 ASCII、十进制、十六进制、八进制转换查看工具。

打印文件的十六进制表示形式，重复的行用 '*' 替代。

```sh
hexdump 路径/到/文件
```

以十六进制显示输入偏移量，并在最后两列中显示其 ASCII 表示形式。

```sh
hexdump -C 路径/到/文件
```

显示文件的十六进制表示，但只解释输入的指定字节数。

```sh
hexdump -C -n 字节数 路径/到/文件
```

不使用 '*' 替换重复的行。

```sh
hexdump -v 路径/到/文件
```

## strings

提取二进制文件中的可打印字符串。

显示长度至少为八个字符的字符串。

```sh
strings -n 8 sample.bin
```

## fold

将长行按指定宽度折行。

在空白处折行，目标宽度 72 列。

```sh
fold -s -w 72 notes.txt
```

## column

把分隔文本对齐为列。

按逗号分隔简单字段并对齐。

```sh
column -t -s ',' table.txt
```

## unexpand

将空格转换为制表符。

将每个文件中的空格转换为制表符，并写入到 `stdout`。

```sh
unexpand 路径/到/文件
```

将空格转换为制表符，从 `stdout` 读取。

```sh
unexpand
```

转换所有空格，而不仅仅是开头的空格。

```sh
unexpand -a 路径/到/文件
```

仅转换开头的空格序列（覆盖 -a）。

```sh
unexpand --first-only 路径/到/文件
```

将制表符间隔设置为某个字符数，而不是 8（启用 -a）。

```sh
unexpand -t 数量 路径/到/文件
```

## diff

比较文件或目录。

比较文件 （列出从`原文件`到`新文件`的修改）。

```sh
diff 原文件 新文件
```

比较文件，忽视空白字符。

```sh
diff -w 原文件 新文件
```

比较文件，并排展示文件差异。

```sh
diff -y 原文件 新文件
```

比较文件，以统一形式展示不同区别 （ 形式同 `git diff`）。

```sh
diff -u 源文件 新文件
```

递归地比较目录 （展示不同文件和目录的名字和差异）。

```sh
diff -r old_directory new_directory
```

## diff3

逐行比较三个文件。

比较文件。

```sh
diff3 路径/到/文件1 路径/到/文件2 路径/到/文件3
```

展示所有的变化，同时列出冲突。

```sh
diff3 -A 路径/到/文件1 路径/到/文件2 路径/到/文件3
```

## cmp

按字节比较两个文件。

显示首个不同字节的位置。

```sh
cmp first.bin second.bin
```

## comm

按行比较已排序的文件。

只列出两个文件共有的行。

```sh
comm -12 sorted-a.txt sorted-b.txt
```

## patch

根据统一差异文件更新源文件。

试算补丁能否应用，不写入文件。

```sh
patch --dry-run -p1 < change.patch
```

## delta

Git 和 diff 输出的查看器。

比较文件或目录。

```sh
delta 路径/到/旧文件或目录 路径/到/新文件或目录
```

比较文件或目录，显示行号。

```sh
delta -n 路径/到/旧文件或目录 路径/到/新文件或目录
```

比较文件或目录，并排显示差异。

```sh
delta -s 路径/到/旧文件或目录 路径/到/新文件或目录
```

比较文件或目录，忽略任何 Git 配置设置。

```sh
delta --no-gitconfig 路径/到/旧文件或目录 路径/到/新文件或目录
```

比较，根据终端模拟器的超链接规范，将提交哈希、文件名和行号渲染为超链接。

```sh
delta --hyperlinks 路径/到/旧文件或目录 路径/到/新文件或目录
```
