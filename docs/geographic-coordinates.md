# 经纬度工具使用说明

“时间与数值 → 经纬度工具”提供格式转换、圆周点计算、文本提取三个页签。全部离线处理，不请求定位或地图资源；各页签分别保留输入和结果。结果只在内存中，主动保存工作区除外。

## 格式转换

分别输入经度、纬度，支持以下写法：

```text
116.3913                  39.9075
116°23′28.68″E            39°54′27″N
东经116度23分28.68秒       北纬39度54分27秒
E116°23'28.68"            N39°54'27"
```

也可粘贴坐标对，再点“填入经纬字段”。此操作只拆分、校验和识别经纬，不转换或重排角度内的文字：度分秒、中文单位、全角数字、方向和小数尾零都保留，只有两端空白及坐标对的外括号被移除。有 E/W/N/S 或中文标签时自动识别顺序；没有标识时使用“原文无标识时的顺序”，默认经度、纬度。需要转换时再点“转换坐标”。

转换只读取当前经度、纬度字段；未填写时提示输入，不借用文本提取页中保留的文本。

- 经度 -180～180°，纬度 -90～90°；分和秒均须小于 60。
- 西经/南纬输出负十进制度；显式正负号与半球冲突时拒绝处理。只接受单个角度，不执行角度加减表达式。
- 默认十进制度小数 6 位、秒小数 2 位，分别可调 0–10 位、0–6 位；秒舍入到 60 时正确进位。
- 内部计算不提前截断；十进制度接受完整浮点小数和有限科学计数法，提取结果用作圆心、计算结果送到格式转换都保留原数值。显示位数不代表数据本身的准确度。
- 仅改变表示方式，不转换 WGS84、GCJ-02 或 BD-09 坐标基准。

## 圆周点计算

输入圆心和半径（米/千米），选择正北 0°、正东 90°、正南 180°、正西 270°，或一次生成全部四方向。

| 算法 | 模型与用途 |
| --- | --- |
| 椭球测地线（默认） | WGS84 参考椭球，GeographicLib / Karney 正解；请提供 WGS84 圆心。 |
| 球面大圆 | 平均地球半径 6,371,008.8 米，球面目的点公式；与椭球结果会有模型差异。 |

半径是所选模型下的地表测地线距离，方向是**起始方位角**。正东/正西终点纬度可能变化；这不是沿纬线移动，也不是屏幕投影中的平面圆。不自动识别或修正高德/百度偏移坐标。

半径 0～10,000 km；0 返回圆心。非零半径不接受恰位于南北极的圆心，因为当地四方位参考不唯一。跨日期变更线的经度规范化为 -180～180°。

结果同时显示十进制度和度分秒，每个表示旁有独立复制按钮，始终复制该行所见数值，不随下方整批复制格式变化。可复制任一表示的坐标对，或送到格式转换。计算产生的新点用完整十进制度传递，避免提前舍入。

## 文本提取

```text
点位 A：东经116度23分28.68秒，北纬39度54分27秒。
点位 B：(121°28'25.2"E, 31°13'49.8"N)
点位 C：N39°54′27″ E116°23′28.68″
点位 D：116°23′28.68″，39°54′27″
```

- 支持常见 ASCII/Unicode 分秒符号、中文单位、全角数字、方向前后缀和经度/纬度标签。
- 优先根据方向/标签配对；点位 D 使用指定原文顺序，不凭两个角度都在 90° 内猜测顺序。
- 允许坐标组内逗号、空白和换行，不跨无关文字或空白段落硬配对。同类方向、越界或孤立角度进入“待核对”，不会复制为有效坐标。
- 每行保留来源行号和原文片段；复制默认只有清洗后的坐标。
- “用作圆心”保留识别出的经纬原文（例如度分秒仍是度分秒），不受表格复制格式或显示精度影响。填入、载入示例、导入及点位传递均可通过输入区的撤销恢复。
- 默认保留顺序和重复点；主动去重按未舍入数值判断，不将显示精度下看似相同的近邻点合并。
- 最多 300,000 字符、10,000 个角度候选（5,000 对）；超限报错。每页 50 对，“复制全部”包含所有页；待核对项仅展示前 200 条。
- 只提取完整度分秒坐标对，不扫描裸数字、时间、UTM 或投影坐标。不保证理解所有自由叙述，提取后仍可对照原文核查。

## 复制、导出和工作区

可选十进制度/度分秒、经纬顺序、CSV/TSV 和表头；支持复制全部、经度列、纬度列、单行，以及导出文件。CSV 转义引号，TSV 可直接粘贴表格。复制不夹带来源或诊断。

输入或计算参数改变后，旧结果保留但停止复制，直到重新运行；只改显示精度、样式或复制设置时，重新格式化已有的未舍入结果。切换页签可使用该页仍匹配输入的结果。恢复工作区后输入和三个页签参数保留，结果需重新运行才能复制。

沿用 Worker、10 秒超时、取消和重试，不自动记录坐标历史。工作区文件包含明文坐标数据，请按实际内容保管。

## 实现与验证

依赖 geographiclib-geodesic / geographiclib-dms 2.2.0，均为 MIT、无运行时依赖。球面公式参考 [Movable Type](https://www.movable-type.co.uk/scripts/latlong.html)，球面半径与 [Turf helpers](https://github.com/Turfjs/turf/tree/master/packages/turf-helpers) 一致。许可见 [GeographicLib 许可](geographiclib-license.txt)。

验证包含官方测地线测试向量、赤道解析结果、精度往返、日期变更线、非法输入、提取与去重、复制格式、工作区恢复；Electron 验证实际运行两个模型和三个页签，读取系统剪贴板核对内容，检查深浅主题及窄屏。
