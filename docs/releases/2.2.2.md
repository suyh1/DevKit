DevKit 2.2.2 增加了局域网快传续传、文件校验和接口集合回归。项目中心可以直接查看关联服务的运行情况，桌面和窄屏的长表单也更容易操作。

## 文件与文本工具

- **快传支持暂停和续传。** 使用「主机暂存」上传文件时可以暂停。在同一标签页内，10 分钟内用相同文件、有效期和取件密码再次发送，会从主机已确认的位置继续。主机重启会清除未完成的上传。
- **批量核对文件。** 在「哈希计算」中拖入多个文件即可计算 SHA-256，也可以导入或导出 `SHA256SUMS`，逐个核对下载文件。
- **复用文本处理步骤。** 在文本工具底部保存多步处理流程，换一份原文即可重跑并查看每一步的结果。比较 JSON 时还可指定要忽略的字段路径，直接查看其余差异。

## 接口与运维

- **按顺序回归一组接口。** 在 HTTP 调试的「接口集合回归」中，可以把上一步响应里的值传给下一步，检查状态和 Schema，并导出结果报告。
- **从项目查看关联服务。** 编辑项目时可关联 API 项目、JAR、Nginx 和监控。从项目卡片打开「运维总览」，即可查看实例状态和最近故障。关联 JAR 的故障时间线还可直接查看故障前后 5 分钟的日志。
- **提前获知证书到期。** HTTPS 监控显示证书到期时间，可在 Webhook 设置中启用剩余 30 天和 7 天的提醒。

## 桌面与窄屏

- 「添加项目」「添加 JAR」「添加监控」和「局域网共享」只滚动表单正文，标题、关闭和保存操作始终可见。下拉选项、滚动条和字号滑杆随主题切换。
- 项目中心窄屏下可连续浏览档案和项目，三种排序方式均可直接选择。方案对比会逐项列出各档案的值，无需横向来回拖动。JAR 主机检测、Nginx 操作栏、主机导入和工具选项的按钮排版也已调整。
