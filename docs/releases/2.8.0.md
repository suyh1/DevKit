- 新增共享栏目「跨网互联」。当 B 和 C 都能连接中间设备 A 时，只需在三台设备中的一台运行 DevKit。在「原 IP 双向互通」中填入三个 IP，桌面端会尝试识别连接地址。在 A 可以直接为两端转发、且具备管理权限的现场，点「检测并配置」即可让 B、C 用原 IP 互访已开放的服务，新增端口也沿用同一条路由。
- 缺少 SSH 管理档案时，可以在方案内填写账号、核对目标设备的指纹并继续。DevKit 装在 B 上时会自动通过已信任的 A 连接 C，装在 C 上也能通过 A 连接 B。
- 共享网页也可以先填三个 IP。有检测权限时可识别地址并保存方案；遇到不确定的地址时，可保存草稿，在桌面端接着配置。需要手动填写时，页面用实际例子解释从哪台设备连接哪个 IP。
- 只需要访问某个服务时，可选「服务转发」。DevKit 会根据安装位置检测可用的连接方式，分别列出访问入口和目标服务，支持 SSH、SFTP、被动 FTP 和其他 TCP 服务。
