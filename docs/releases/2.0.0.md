- **工作台总览和工具库**　悬浮导航和分区卡片保留原有入口。可从总览继续上次任务，也可直接进入工具库，按分类、收藏或最近使用筛选，并在卡片和列表间切换。
- **46 个工具和 12 个共享栏目**　短选项可以直接点选，例如坐标复制格式、渐变类型、快传发送方式和白板线宽。Tab 可进入选项组，方向键切换，Home 和 End 跳到首尾。项目分组、主机和文件等动态列表继续使用下拉选择。
- **主题和文字**　九套主题均支持浅色和深色。编辑器、差异、摘要和生成结果使用等宽字体并支持中文回退。SSH 终端可在会话中跟随主题和代码字号调整。
- **文件与加载反馈**　编辑器和共享列表读取时显示骨架占位。超长文件名可在悬停时滚动查看，减少动态效果时可换行阅读。
