DevKit 2.6.0 新增「共享栏目 → Git 仓库管理」。可以在桌面登记或克隆仓库，再按需发布到共享网页。浏览器和桌面操作主机上的同一份工作树与暂存区。共享主机需要安装 Git 2.32 或更高版本。

## 从审阅改动到推送

- 查看文件差异，按文件或差异块暂存、取消暂存。提交前可核对分支和已暂存文件，写好说明后按 Ctrl+Enter 或 ⌘+Enter 提交。
- 「提交后预览推送」会列出目标远端、分支和待发送的提交，确认后再推送。还可以比较提交、查看文件历史、管理贮藏和合并分支。
- 在「仓库访问权限」中设置默认权限，也可为指定访客单独授权。新登记的仓库发布后，访客默认只能查看提交历史。

## 共享网页与工作台

- 网页侧栏只有栏目列表滚动，排序入口与主机地址固定可见。克隆、推送预览等辅助操作使用弹窗，多行输入框随内容增高，达到上限后在框内滚动。
- 网页「外观 → 关于 DevKit」与客户端共用信息列表，可查看版本和许可、复制作者邮箱、打开 GitHub 仓库。
- 总览的内容匹配覆盖全部本机工具和共享栏目，可根据粘贴的内容推荐入口，并带入相应的输入或模式。
