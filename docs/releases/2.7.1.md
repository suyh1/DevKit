## Git 仓库管理

桌面端和共享网页都可以逐个文件或跨页勾选后批量暂存、取消暂存，也可以在差异预览中只暂存某个改动块。工作区和暂存区各按 50 个文件分页。提交和推送入口位于文件列表上方，改动再多也能直接打开提交窗口或推送预览。

提交图按父提交连接分叉与合并。翻页查看较早的记录时可以沿分支继续追踪，点选提交即可查看差异。

## 服务管理与长列表

服务列表每页显示 20 项。点击服务所在行的「日志」或「控制台」即可查看该服务的输出，按 Esc 回到原来的服务。日志中心也可以从来源列表跳到所选日志，再返回对应来源。

局域网快传的发送和暂停按钮移到文件清单前。HTTP 接口集合的追加、保存、运行和停止按钮也移到步骤列表前，处理长清单时可以直接操作。

## 原位展开与独立面板

完整路径、知识库筛选、服务健康检查和日志轮转等短内容可直接在当前位置展开。共享网页的「主机与权限」也可以就地查看。表格中的短记录在当前行下方展开，多字段或多行记录可点窗口图标查看完整内容。
