- 在「共享栏目 → 跨网互联 → 网段互联」填写跳板机 A 的 IPv4，点「读取 A 的网段」，即可查看 A 的直连网段和显式路由。若 A 依靠默认路由访问某个内网，可手动补入其前缀。读取远程 A 时使用已确认指纹的 SSH 档案。
- 在桌面按现场拓扑导出配置。B 或 C 与 A 直连时可选「网关路由」，隔着其他网关时可选 WireGuard 三层隧道。两侧可分别选择。配置转发和回程后，可用目标主机的原 IP 和端口访问服务。
- 直连配置会保留 A 通往更具体子网的路由。如果安装配置的网关本身就是 A 到某个子网的下一跳，它会保留已有去程，避免流量在两台设备间循环。
- 重新导出时会排除 DevKit 自己的隧道，并在地址段仍可用时沿用它。A 的转发脚本会先检查接口和 NAT，中途失败时会尝试恢复本次改动。服务转发的正向和反向 SSH 检测都会沿已保存的跳板链连接。
