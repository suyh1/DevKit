DevKit 2.2.5 将「JAR 管理」升级为「后端管理」。已有 JAR 配置会自动出现在新栏目中，运行中的服务可继续管理，无需重新登记或为了升级而重启。

## 添加后端服务

- **Java JAR**　继续使用原有的 JVM 参数、应用参数、日志、守护和自启设置。Java 检测已移到 JAR 配置表单内。
- **npm 项目**　选择项目目录后，可从 package.json 读取脚本，使用 npm start 或其他项目脚本启动。每个服务都可以指定自己的 Node.js，同一台主机上的项目可以使用不同版本。
- **可执行程序**　可直接登记 Go 等语言编译的 Windows 或 Linux 程序，设置工作目录和启动参数。保存前可检查文件格式，Linux 还会检查执行权限。

## 选择目标主机上的 Java 和 Node.js

在添加或编辑服务时点击「查找已安装版本」，即可按版本号和实际路径选择，也可以手动选文件或输入绝对路径。npm 项目的检测、启动和重启使用所选 Node.js 及配套 npm。清空路径后，服务继续按环境中的 PATH 查找。

## 日志、监控与共享

项目中心可关联后端服务，日志中心和监控中心可查看 npm 项目、可执行程序的日志与健康状态。升级后，如需让共享访客管理这两类服务，请在共享设置中勾选「包含 npm 与可执行程序」，再按需要授予编辑和运行权限。
