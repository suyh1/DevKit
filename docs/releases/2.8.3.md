- SFTP 会话现在左侧显示本机，右侧显示目标主机。右键本机文件或文件夹可上传，右键远端条目可下载。传输队列显示进度，失败的任务可单独重试。
- VNC 支持按显示号连接，如 `10.190.11.17:1` 会连接 TCP 5901。共享网页可以从共享主机直连 VNC，也可以使用 guacd 网关。
- 修复 VNC 收到异常或超大剪贴板消息时会断线的问题。操作远端 Linux 终端时，勾选「终端复制粘贴」即可用本机 Ctrl+C、Ctrl+V 复制和粘贴。
- Linux 更新 DevKit 后，服务管理可重新识别仍在运行的本机服务，保留原进程并恢复启停操作。如果启动进程确实退出，身份核实通过的业务进程组也可以从界面停止。
