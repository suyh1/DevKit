DevKit 2.3.0 新增 5 个离线工具，并升级 5 个常用工具。现在可以把逐行日志整理成数组、把表格贴进文档，也可以在本机完成配置比对和跨时区换算。基础工具现有 51 个。

## 新增工具

- **JSON Lines ↔ JSON 数组**　将每行一条的 JSON 记录合并为数组，或把数组拆成逐行记录。转换保留大整数和指数写法，遇到坏行会指出原始行号。
- **Markdown 表格转换**　把 CSV 或 TSV 转成可粘贴进 README 的 Markdown 表格，也能反向转换。编号前导零、空单元格和单元格内的竖线都能保留。
- **离线二维码生成**　输入文本或链接即可预览二维码，支持中文、emoji，可选择尺寸和纠错级别并保存为 PNG。
- **SemVer 版本范围检查**　粘贴候选版本，再输入类似 `^1.2.3` 的 npm 版本范围，即可查看最高匹配版本和降序列表。无效版本单独标明行号。
- **CSS Flex 布局预览**　调整容器宽度、方向、换行、间距及对齐方式，实时查看子项排列，再复制对应的容器 CSS。

## 现有工具升级

- **JSON Schema**　可直接用推断出的 Schema 校验样本，也可粘贴自己的规则。校验报告给出失败字段的路径，并区分规则无效、样本不合规和引擎无法判定。
- **文本与 JSON 差异**　左右两侧都支持选择或拖入文件。交换两侧时，文件名和编码随内容一起移动。
- **正则测试**　新增替换模式，支持编号和命名捕获组。可以查看匹配次数，复制替换后的全文或发送到下一个工具。
- **.env 配置**　可按键比较两份配置，分别查看仅左侧存在、仅右侧存在和值有变化的键。默认显示键名，展开单项即可核对两侧的值。
- **时间戳转换**　支持逐行换算到指定 IANA 时区，结果显示当地时间和 UTC 偏移。坏行在原位置标出，整批结果可复制或导出为 TSV。
