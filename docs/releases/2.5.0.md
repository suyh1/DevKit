DevKit 2.5.0 完善了接口模拟服务。现在可以从 HTTP 接口文档生成响应、按请求内容切换场景，还可以用同一组订单或用户记录联调增删改查。

## 从接口定义生成 Mock 数据

- 在「接口模拟服务 → 导入与数据集」选择 HTTP 工作台中已有的接口。有响应示例时会保留示例，只有响应 Schema 时，会按字段类型、枚举、取值范围、日期等常用约束生成数据。发布前即可预览。
- 手头没有接口文档时，可直接套用订单、用户或商品模板，调整字段和条数。发布后，每次调用都会重新生成数据。

## 按请求选择场景，复现实际调用

- 路径参数、查询参数、请求头和 JSON 正文字段既能填入响应，也能作为场景条件。例如，调用 `/orders/42` 可以返回订单号 42，加上 `?mode=empty` 可以切换到预设的空数据场景。
- 在「调用与记录」可以看到实际耗时，以及命中某个场景或回退到默认场景的原因。展开记录，点「带入 HTTP 调试」，即可检查、修改并重新发送请求。常见凭据字段会自动省略。

## 用一份数据联调多个接口

- 同一项目的接口可以共用一个基础地址。新建项目数据集后，列表与详情会读取同一份记录。
- 数据集默认只读。开启写入后，新建或修改的记录会出现在后续查询中，重启共享主机后仍会保留。需要重新演示时，可恢复到首次生成的记录。

## 给编辑器和常用操作留出空间

- Nginx 配置页把实例路径收成一行。展开即可查看主配置、运行目录、Nginx 程序和 PID 文件。
- 模拟接口优先显示响应编辑、预览和保存。手机共享页将「邀请设备」放在「主机与权限」旁，快传、模拟接口和白板都能更早显示正文。
- 文件工具先显示选取和处理操作，经纬度工具先显示坐标转换和结果。监控计数合并为一栏，知识库的项目与标签筛选、偏好设置里的主题风格均可按需展开。
