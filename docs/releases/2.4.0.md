DevKit 2.4.0 新增 44 个本地开发工具，工具总数由 51 个增至 95 个，并升级了 16 个已有工具。文件处理、结构化文档编辑和共享网页的手机布局都有改进。

## 文件与数据处理

- 在「站点图标包」选择母图后，可以先看浏览器标签和应用图标的效果，再一次下载多尺寸 PNG、ICO、Web Manifest 和 HTML 引用片段。
- 双文件工具支持一起拖入两份文件，也可以单独替换一侧。截图对比和图片压缩支持拖动分界线查看差异。
- 批量时间戳、Markdown 表格、CSV 格式的 Mock 数据和 URL 查询参数支持筛选、翻页与展开行详情。筛选 JSON 数组时仍可看到原始行号。

## 文本与代码编辑

- JSON Patch 可以并排编辑源文档、目标文档和预演文档，逐行核对修改结果。应用已有补丁时，只显示补丁与待修改文档。三方合并也使用带行号的编辑器。
- 普通文本框和多行输入统一了焦点、校验和只读状态。搜索框保留整条搜索栏的输入边界，浅色和深色主题均可使用。

## 共享工作台

- 手机上编辑 HTTP 接口时，每个参数单独成行，类型、示例和移除按钮都在当前屏内。接口模拟服务可按状态码和名称切换场景，区分正在编辑和已经生效的配置。
- 修复了长清单名撑出选择框、长接口名显示不全，以及窄屏工具栏遮挡正文的问题。编辑弹窗的保存与取消集中在底部，窗口进入后台时也能完成关闭。
