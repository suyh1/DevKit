DevKit 2.2.4 修复了桌面工作台、共享门户和独立快传页中的 26 项界面与交互问题。共享栏目排序框的文字已垂直居中。保存工作区时可以确认实际会写入的任务数，查看 JSON 结果时也更容易区分筛选无匹配和重复字段。

## 排序、取色与编辑

- 「排列共享栏目」中的位置文字与箭头对齐，一位数和两位数位置都能清楚辨认。用键盘可在合拢的位置框上按 Home 或 End，把栏目移到首位或末位。「工具处理流程」的已存流程选择框也已对齐。
- 在色板上更换颜色会保留原有透明度。图片取色时，修改 X 或 Y 坐标会同步刷新放大镜和预览色值，点击「取此像素」才会应用到主颜色。
- 最大化输入区或结果区后，按钮提示会变为「还原输入区」或「还原结果区」。Nginx 配置页签遇到同名文件会补充可区分的父目录，并提供完整路径。

## 结果查看与工作区保存

- JSON 表格可按字段或值筛选，并保留原始行号。预览遇到同名字段时，会提示切换到结构视图或源码查看全部值。结构树、HTTP 快速请求集合、模拟接口和画板库在搜索无匹配时都会给出提示。
- 展开工具流程步骤时，超过 8,192 字符的输入和输出会显示预览长度与完整长度。「复制完整输出」仍可复制全部内容。滚动结果时，「复制选区」会随所选文字离开可视区域而收起，滚回时重新出现。
- 工作区默认排除密码、JWT 和 HMAC 任务，偏好设置与保存窗口的说明已统一。可保存任务为零时，窗口会说明原因并禁用保存按钮。知识库底栏会说明写作草稿存放在本机。
- 全局通知分别使用成功、错误和普通提示图标。切换资源后，复制链接按钮会清除上一条链接的复制状态。

## 共享文件与局域网快传

- 浏览共享文件夹时，空目录和筛选无匹配有不同提示，可点击「清除筛选」返回完整列表。
- 快传首次读取收件箱失败时会显示重试入口。后续刷新失败时保留上次成功读取的内容，并提示当前状态。发送一批文件或文字后，只汇总一次已发送数、剩余数和失败原因。
- 在窄屏打开独立快传页时，手动复制弹窗、文本框和关闭按钮可在屏幕内完整显示。

## 键盘导航与焦点

- 关闭任务后，焦点移到相邻任务标签；关闭最后一个任务时回到工作台导航。从未保存更改的确认框选择「继续编辑」，可以接着修改草稿。导入文件时，Tab 会停在可见的操作入口。
- 全局搜索用上下方向键选择结果，Tab 可直接离开结果列表。「Shift + Enter 新建任务」只在选中工具时显示。共享门户的搜索窗口会向读屏软件说明搜索范围是共享资源。
- HTTP 模式、API 接口视图、响应区域、Nginx 文件和 SSH 会话的页签均支持左右方向键切换，Home 和 End 可跳到首尾可用页签。SSH 切换会话时保留页签焦点，关闭按钮仍可独立操作。
