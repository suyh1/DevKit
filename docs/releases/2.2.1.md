DevKit 2.2.1 让局域网快传的地址可以直接念给对方，也让发布者能重新查看自己设置的取件密码。

- **用 IP 和端口打开快传。** 新建快速链接后，同一局域网内的收件人只需在浏览器输入主机 IP 和快传端口，例如 `http://192.168.1.20:8780`，即可进入快传收件箱，无需共享口令或访客账号。升级前的长链接继续有效。主机勾选「为旧端口开启短地址」并保存后，两种地址都能用。
- **回看自己的取件密码。** 发送带密码的文件、文字或链接后，在原发布设备的同一快传入口找到该项，点击「查看我的取件密码」，核对后可点「隐藏取件密码」。共享工作台访客需回到原登录标签页。此功能适用于升级后发送且仍有效的项目，接收方仍需凭密码取件。
