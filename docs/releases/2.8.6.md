- 新增 macOS Apple Silicon (M 系列芯片) 无签名 `.dmg` 安装包发行（内置 ad-hoc 签名），并在 GitHub Releases 与 Windows x64、Linux amd64、Linux ARM64 同步构建和校验。打包版 macOS 将配置与数据存放在 `~/Library/Application Support/DevKit/configs/`，覆盖升级不会丢失配置。
- 全面适配 macOS 桌面与本机运维功能：支持基于 `ps`/`lsof`/`sysctl` 的本机 JAR/服务进程与进程组状态探测、Mach-O 可执行程序格式检查、Nginx macOS 实例与工作进程检测、Homebrew/常见路径的 Java 与 Node.js 自动发现、`~/Library/LaunchAgents/` 登录自启、局域网邻居 MAC 读取、菜单栏托盘图标适配及系统 RDP 客户端唤起。
- 仓库根目录新增 macOS 源码预览脚本 `start-preview-mac.command` 与 Linux 源码预览脚本 `start-preview-linux.sh`，与 Windows 的 `start-preview.cmd` 一样支持自动检查 Node.js 24+、按需安装依赖并直接启动桌面预览。
