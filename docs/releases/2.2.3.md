DevKit 2.2.3 新增「团队知识库」。团队可以在局域网里共写术语表、发布指南和交接文档，并从文档直接打开对应的 JAR、Nginx 和监控项。桌面和共享网页也统一了输入与键盘焦点的提示。

## 团队知识库

- **从空白页开始写作。** 打开「共享栏目 → 团队知识库 → 新建文档」即可进入独立编辑页。需要提纲时可选部署手册、故障排查或项目交接模板。用多级目录、项目和自定义标签整理文档。
- **写长文时随时预览和续写。** Markdown 正文和常见配置代码块支持语法高亮。宽屏可分栏对照，窄屏可切换编辑和预览，返回时保留光标与滚动位置。离开或刷新后，可从同一设备的本机草稿继续写。
- **一次引用多个栏目的资源。** 勾选多个 JAR 实例、Nginx 配置、监控项或其他文档，切换栏目和搜索词会保留已选项。从 JAR 或 Nginx 的「关联手册」入口新建，可以直接带入实例名称、所属主机和链接。
- **找到需要的段落。** 全文搜索显示命中片段，点击结果可跳到正文。通过「本文目录」可复制章节链接，文末还可查看有哪些文档引用了本文。
- **共享和版本管理。** 在共享设置中开启知识库，并为访客分配查看或编辑权限。主机保留最近 20 个旧版本。两人同时修改同一篇文档时，后保存的人可以对照主机版本合并内容，也可以将草稿另存为副本。

## 控件焦点

- 输入框和选择框获得焦点时，底部显示一条主题色细线。带图标的搜索框共用一条底边，代码编辑器在可视区侧边标记当前输入位置。
- 用 Tab 切换按钮、链接和分段选项时显示细轮廓。焦点配色跟随九种主题风格及深浅模式，系统强制颜色模式使用系统高亮色。
