- **工具库**　卡片依次轻轻上弹。移动鼠标或触碰卡片时，卡面随指针倾斜，反光和渐变描边跟随变化，底部光晕缓慢呼吸。松手后卡片回正，点击主体可连续展开到对应工具。
- **搜索与操作按钮**　点击顶部搜索胶囊，搜索面板会从按钮所在位置展开。运行、保存和复制等按钮按下时缩至 96%，松开后轻微回弹。
- **监控中心**　在响应耗时曲线上横向拖动，游标会吸附到最近的检测点，上方同步显示检测时间和滚动的毫秒读数。也可用左右方向键逐点查看，按 End 回到最新检测。
- **窄屏共享导航**　栏目导航从底部打开。拖动手柄时，越过边界会有阻力，松手后会按位置和速度停在半屏或展开高度。点击手柄或聚焦后按 Enter，也能在两个高度之间切换。

系统启用“减少动态效果”或工作台使用性能模式时，界面直接切换到目标状态。
