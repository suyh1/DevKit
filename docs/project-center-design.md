# 项目中心交互约定

- 视觉随工作台统一：浅色为灰白与蓝色，深色为石墨灰表面、柔白文字与雾蓝交互；启用和检测通过使用独立的绿色成功状态。保留圆角表面、柔和过渡与紧凑项目卡片。卡片 / 列表采用共享分段控件，初次连接与数据加载提供 Skeleton；桌面、网页及弹窗加载同一份主题变量与样式。完整配色和动效约定见 [界面设计说明](interface-design.md)。

- 沿用应用现有中性色、强调色和本地字体；采用紧凑管理界面，不使用营销式首屏或远程字体。设计技能检索采用可访问性、清晰反馈与数据管理建议，舍弃不适用的作品集布局。
- 左侧为配置档案，主区为当前档案入口；项目和变量归属于当前档案，所有编辑始终显示作用范围。当前档案选择由每位访问者独立保存。
- 每个档案对应 configs 中一个独立 JSON；新建档案为空，复制产生独立副本，旧版共享项目与覆盖自动展开迁移并保留原始备份。
- 卡片直接展示项目删除入口；删除仅作用于当前档案，移除档案则一并移除所属项目、变量和文件。
- “对比方案”按项目编码对齐并集，明确标记项目缺失，展示名称、分组、说明、启停、模板、全部参数与最终地址和变量。
- 主区支持卡片/列表、搜索/分组/状态、排序。批量操作只作用于明确勾选的项目；切换档案清空勾选。
- 手动探活分三个入口：单项目“探活”、当前配置“全部探活”、勾选后的“检测所选入口”。“全部探活”明确覆盖当前档案全部已启用项目，不受筛选及勾选限制；停用计为跳过，配置异常计为失败。检测逐项更新，进度与成功/失败/跳过数就近展示；结果含文字状态、耗时、时间及主机检测标识。检测期间禁用重复操作，切换档案或重新读取/保存配置清除旧结果；不自动轮询、不持久化。
- 编辑弹窗分为基础信息、地址与参数、最终地址预览；预览解释协议/主机/路径/查询参数，仅使用当前档案变量解析地址。空白参数行忽略，有值无参数名报错。
- 编辑关闭前检查草稿；Esc、关闭按钮和取消使用同一逻辑。危险操作用应用内确认；保存中避免重复操作。冲突保留草稿，刷新不自动覆盖输入。
- 导入默认合并：同名档案内按项目编码和变量名合并，处理 ID 碰撞并保留未导入内容；允许明确选择全量替换，提交前展示影响范围。
- 恢复先展示快照内容和当前数据对比；确认后新增版本，保留恢复前备份。支持快照自定义名称。
- 主机显示 configs 实际路径、打开目录和复制迁移说明；网页说明数据存于主机，不暴露主机文件操作。configs 不可写时明确报错，无隐式备用位置。
- 窄屏表单、参数行、工具栏和列表按内容重排；交互目标不小于 32px，触屏 44px。保持可见键盘焦点，状态同时使用文字，尊重减少动画设置。
