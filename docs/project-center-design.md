# 项目中心 v1.6 交互约定

- 沿用应用现有中性色、强调色和本地字体；采用紧凑管理界面，不使用营销式首屏或远程字体。设计技能检索采用可访问性、清晰反馈与数据管理建议，舍弃不适用的作品集布局。
- 左侧为配置档案，主区为当前档案入口；项目基础定义与环境覆盖始终显示作用范围。当前档案选择由每位访问者独立保存。
- 主区支持卡片/列表、搜索/分组/状态、排序。批量操作只作用于明确勾选的项目；切换档案清空勾选。
- 编辑弹窗分为基础信息、地址与参数、最终地址预览；预览解释协议/主机/路径/查询参数，标明环境覆盖的优先级。空白参数行忽略，有值无参数名报错。
- 编辑关闭前检查草稿；Esc、关闭按钮和取消使用同一逻辑。危险操作用应用内确认；保存中避免重复操作。冲突保留草稿，刷新不自动覆盖输入。
- 导入默认合并：同编码项目更新、同名档案合并变量/覆盖，处理 ID 碰撞并保留未导入内容；允许明确选择全量替换，提交前展示影响范围。
- 恢复先展示快照内容和当前数据对比；确认后新增版本，保留恢复前备份。支持快照自定义名称。
- 主机显示 configs 实际路径、打开目录和复制迁移说明；网页说明数据存于主机，不暴露主机文件操作。configs 不可写时明确报错，无隐式备用位置。
- 窄屏表单、参数行、工具栏和列表按内容重排；交互目标不小于 32px，触屏 44px。保持可见键盘焦点，状态同时使用文字，尊重减少动画设置。
