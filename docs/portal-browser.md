# 共享网页版使用与验收

登录前可在「共享主机」核对当前地址。使用共享口令时，留空「访客名称」即可登录。使用专属访客口令时，填写主机管理员分配的名称和口令。口令框右侧的眼睛按钮可切换显示或隐藏，按 Enter 提交。手机上，主机地址和表单上下排列。

共享门户使用独立主滚动区，左侧导航随窗口宽度调整。栏目列表为滚动条预留空间，按钮在滚动条出现前后等宽。列表放不下时可在其中滚动，顶部的排序入口和底部的共享主机地址始终可见。780px 及以下通过顶部菜单打开导航抽屉，支持 Tab 聚焦、Esc 关闭和选中后收起。顶栏显示当前栏目、权限、访客名称、搜索和退出入口，长访客名称会截断显示。运行模式、主题风格和明暗主题归入“外观”，点击菜单外部或按 Esc 可收起。点击菜单底部的「关于 DevKit」打开信息窗口，查看版本、作者、联系邮箱、软件许可和 GitHub 仓库地址。窗口内可复制邮箱、查看许可全文或在新标签页打开仓库。Nginx 长内容及 HTTP 编辑正文使用主滚动区，窄屏将接口目录放在编辑区上方。日志中心提供最多四窗独立滚动。详见[日志中心](log-center.md)。

共享栏目内部与桌面共用标题面板、列表选中标记和状态色。桌面与网页使用同一套下拉框和选项样式。支持 Popover 且没有可定制原生下拉框的浏览器使用页内选项列表，可用方向键、Enter、Esc 或键入名称选择。显示的栏目取决于主机开放的服务及访客权限。

手机上，HTTP 接口的标题和工具栏随正文滚动。参数编辑区较窄时，每个参数单独排列，可以直接修改类型、填写示例或移除该参数。接口模拟服务把窄屏场景列表收进选择框，选项显示状态码和名称，并标出当前生效的场景。切换查看的场景后，可以用「设为生效场景」和「保存接口」更新配置。

侧栏和窄屏导航抽屉都提供“排序”。可以拖动手柄、选择位置或用上下箭头微调。保存后两个入口使用同一顺序，刷新页面仍会保留。排序和恢复默认只作用于当前访客可见的栏目，偏好保存在当前浏览器的共享站点。

## 路由、数据与反馈

点击关联入口时会检查当前访客的栏目和操作权限。栏目未共享、没有编辑权限或缺少日志类别授权时，气泡会说明原因，当前页面和草稿可继续使用。

| 所在位置 | 可以前往的位置 |
| --- | --- |
| 服务管理文件替换 | 在服务列表直接点击“替换服务文件”，即可停服、从浏览器上传新 JAR、程序或入口脚本，并按需备份和启动。也可在“恢复历史备份”中选择该主机上的旧版本并恢复启动。 |
| 服务管理、Nginx 配置 | 在实例表单中查看或新建目标主机。保存或取消后回到原表单，主机选项重新加载。实例可直达自己的日志；应用服务还可查看关联监控和项目，按项目编辑权限维护关联。 |
| 局域网主机 | 从主机查看对应的应用服务或 Nginx 实例、主机日志及端口监控。在 SSH 档案内可新建并选择跳板机。 |
| 日志中心 | 从日志窗回到产生该日志的实例或主机，从来源列表登记新的应用服务、Nginx 实例或主机。 |
| 项目中心、监控中心 | 从项目或应用服务查看该来源的监控，新建时自动填写来源。从监控可返回具体项目、应用服务或主机。编辑检测来源时也可直接新建项目、应用服务或主机，返回后继续编辑。 |
| HTTP 调试、接口模拟服务 | 把已保存接口的方法、路径和响应示例带入新模拟草稿。在模拟服务中可导入其他 HTTP 接口或去新建接口。发布后可从调用地址打开 HTTP 快速请求，核对后手动发送。 |
| 待办清单、本机文件共享管理 | 在“添加引用”中选择文件共享或工作台栏目。打开引用时定位到对应目标。在文件共享详情可新建包含该共享引用的待办清单。网页的文件共享范围由主机桌面端配置。 |
| 截图协作白板、接口模拟服务、局域网快传 | 在“邀请设备”中把当前画板或模拟服务的邀请地址填入快传，确认后发送。收件箱中的本站工作台链接可直接打开对应栏目或资源；有取件密码的链接需先解锁。 |

- 栏目入口保留 `/#projects`、`/#nginx`、`/#http` 等地址。搜索结果和“复制链接”可直达项目卡片、应用服务或 Nginx 实例、API 接口、监控或日志来源。未登录时先登录，主机按当前访客权限解析栏目和资源。目标已移除、未授权或主机暂时无法读取时，页面显示对应反馈。前进/返回切换服务，各服务的草稿和滚动位置在本页会话中保留。
- 项目与 API 定义保存在共享主机。项目入口由当前浏览器打开，入口探活和 HTTP 调试请求从共享主机发起。应用服务、Nginx 与日志的路径和操作指向实例所在主机。导出文件和快速请求集合属于当前浏览器。
- 开放“局域网主机”后，可访问 `/#lan-hosts` 查看并搜索共享主机保存的清单。按访客权限开放档案管理、连接诊断、SSH 终端、SFTP、主机发现、网络唤醒和远程桌面连接。主机卡片也可打开已获授权的端口监控历史和目标主机日志。
- 已授权的访客可从主机卡片在网页内连接远程桌面，使用键盘、鼠标或触控。网关部署和证书配置见 [网页远程桌面](workspace-sharing.md#网页远程桌面)。
- 操作反馈可关闭并自动消退；切换/丢弃接口草稿会清除先前操作反馈。当前草稿状态独立显示，不由历史通知代表。
- 会话失效可重新登录。相同访客及权限可以继续当前工作，更换访客或权限会清除当前页面的草稿、响应和弹窗。退出接口允许重复注销。离线退出后清空草稿、响应和历史，恢复连接或重试时先注销旧会话。待注销标记只保存在当前浏览器标签会话。

## 复制与草稿

局域网HTTP页面可能不提供现代剪贴板API。复制入口统一优先使用可用的剪贴板接口，再尝试浏览器用户操作内的回退；若浏览器仍拒绝，打开只读手动复制窗口，选中文字后使用Ctrl+C/⌘C或右键菜单。失败不会显示“已复制”，也不会自动上传内容。

HTTP运行调试中的参数、鉴权、正文和超时属于本次请求覆盖值。修改它们不会改写接口定义、默认示例或共享鉴权；“恢复定义值”清除本次覆盖。定义变更仍在“接口设计”完成。历史恢复同样恢复为调试值；“采用为响应示例”是显式修改定义草稿的动作，仍需保存才写入主机。新建接口先显示为左侧“未保存草稿”，保存后进入共享目录，不自动保存。

项目中心按当前档案汇总真正缺少的模板变量，提供定位/补齐入口。在草稿中补齐空变量后需填写并保存才生效；现有变量和项目模板不自动改名、替换或保存。允许保留未完成配置。

## Nginx状态与帮助

Nginx 帮助浮层随应用打包 Popover 兼容层，不需要联网加载。旧版浏览器不支持原生 Popover API 时仍可登录、切换共享模块和查看帮助；隐藏的 Nginx 页面也不会因 `:popover-open` 查询导致整个共享页空白。

回归验证：构建后运行 `node scripts/smoke-portal.mjs --legacy-popover`，模拟缺少原生 API 和选择器的浏览器，检查登录、模块切换、浮层显示与关闭，并执行完整共享页交互检查。

门户将真实主滚动容器传给吸顶组件。滚动到长配置时，顶部导航下方只吸顶检查配置、启动、重载、停止、保存文件一行。实例信息和执行详情收起，字段定位按实际操作栏高度留白。路径与搜索不再带孤立问号，提示只放在实例字段和配置参数附近。

运行状态显示上次成功确认时间。读取失败后保留历史信息但明确标为待重新确认，暂停启停/重载操作，并提供重新确认入口；恢复读取后更新。进入服务时立即复核状态。关闭Nginx表单或弹窗会将键盘焦点返回仍存在的触发按钮。

## 验证方式与边界

`npm run test:portal`构建后运行隔离的真实浏览器回归。测试使用临时目录和模拟Nginx进程信息，不使用用户配置、不执行nginx命令。优先选择本机LAN网卡地址，避免把回环可信来源冒充普通HTTP页面。实际动作使用鼠标命中和滚轮，读取DOM仅用于断言；不通过DOM click绕过裁切。覆盖项目中心1440/1024/390宽度，HTTP1920/1366/1024/390及125%缩放、深色主题，运行状态故障、复制降级、调试隔离、缺变量草稿、浏览器返回和离线/失效退出。截图及结果位于`artifacts/portal-regression/`。

`npm test`包含调试覆盖值和复制结果测试；`npm run test:http`包含匿名/失效会话注销及旧路由兼容测试。完整桌面和既有共享流程仍由`npm run test:electron`、`node scripts/smoke-sharing.mjs`验证。

制作Windows安装包后，`node scripts/smoke-portal.mjs --packaged`使用实际ASAR中的门户资源、服务端及共享模型重复上述交互验证，防止源码通过而包内遗漏。

目标Linux/麒麟桌面、长时间多人并发、系统防火墙和所有浏览器权限策略仍需对应环境验收。回退失败会提供手动复制，不承诺浏览器一定允许写入系统剪贴板。

本次调试值存在覆盖时，重新载入当前接口、切换到其他接口或新建接口会先提示是否放弃这些本页草稿；选择继续编辑会保留，确认放弃会清除覆盖值。切换设计/调试视图或共享服务不会丢弃它们。
