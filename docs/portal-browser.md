# 共享网页版使用与验收

共享门户使用独立主滚动区，顶部服务导航保持可见。项目中心和Nginx长内容在主区自然滚动；HTTP编辑正文也使用主滚动区，接口目录在桌面宽度下保留独立列表滚动，窄屏将目录放在编辑区上方。门户不再继承桌面主窗口的固定裁切布局。

## 路由、数据与反馈

- 三项服务有可复制的入口：`/#projects`、`/#nginx`、`/#http`。未登录时先登录，登录后进入已授权的目标服务；关闭的服务不会因URL被访问。前进/返回切换服务，各服务的草稿和滚动位置在本页会话中保留。
- 项目与API定义保存在共享主机。项目入口由当前浏览器打开，主机入口检测与访客浏览器访问可能有不同结果；Nginx路径/文件/命令及HTTP调试请求属于共享主机。导出文件下载到当前浏览器，快速请求集合也属于当前浏览器。
- 操作反馈可关闭并自动消退；切换/丢弃接口草稿会清除先前操作反馈。当前草稿状态独立显示，不由历史通知代表。
- 会话失效可重新登录；退出接口允许重复注销。即使暂时断网，也可退出本页并清空草稿、响应和历史；恢复连接或重试时先注销旧会话，不会自动重新进入旧会话。待注销标记只保存在当前浏览器标签会话，不包含口令。

## 复制与草稿

局域网HTTP页面可能不提供现代剪贴板API。复制入口统一优先使用可用的剪贴板接口，再尝试浏览器用户操作内的回退；若浏览器仍拒绝，打开只读手动复制窗口，选中文字后使用Ctrl+C/⌘C或右键菜单。失败不会显示“已复制”，也不会自动上传内容。

HTTP运行调试中的参数、鉴权、正文和超时属于本次请求覆盖值。修改它们不会改写接口定义、默认示例或共享鉴权；“恢复定义值”清除本次覆盖。定义变更仍在“接口设计”完成。历史恢复同样恢复为调试值；“采用为响应示例”是显式修改定义草稿的动作，仍需保存才写入主机。新建接口先显示为左侧“未保存草稿”，保存后进入共享目录，不自动保存。

项目中心按当前档案汇总真正缺少的模板变量，提供定位/补齐入口。在草稿中补齐空变量后需填写并保存才生效；现有变量和项目模板不自动改名、替换或保存。允许保留未完成配置。

## Nginx状态与帮助

Nginx 帮助浮层随应用打包 Popover 兼容层，不需要联网加载。旧版浏览器不支持原生 Popover API 时仍可登录、切换共享模块和查看帮助；隐藏的 Nginx 页面也不会因 `:popover-open` 查询导致整个共享页空白。

回归验证：构建后运行 `node scripts/smoke-portal.mjs --legacy-popover`，模拟缺少原生 API 和选择器的浏览器，检查登录、模块切换、浮层显示与关闭，并执行完整共享页交互检查。

门户将真实主滚动容器传给吸顶组件。滚动到长配置时，操作栏在顶部导航下方吸顶并收紧详情，字段定位留出操作栏高度。路径与搜索不再带孤立问号，提示只放在实例字段和配置参数附近。

运行状态显示上次成功确认时间。读取失败后保留历史信息但明确标为待重新确认，暂停启停/重载操作，并提供重新确认入口；恢复读取后更新。进入服务时立即复核状态。关闭Nginx表单或弹窗会将键盘焦点返回仍存在的触发按钮。

## 15项问题对应修复

| 审查项 | 实现与验收重点 |
| --- | --- |
| 1 页面裁切 | 桌面main规则限定作用域；门户主区滚轮到底，底部按钮可见且可命中 |
| 2 HTTP高度 | 门户下去除固定扣减和最小高度叠加；长定义正文到底可达 |
| 3 Nginx吸顶 | 实际滚动根、紧凑模式、导航下方位置及定位留白 |
| 4 LAN复制 | 真实局域网HTTP自动回退成功；完全拒绝时手动复制 |
| 5 调试污染定义 | 修改调试值后设计示例、鉴权、正文和共享文件不变 |
| 6 旧状态伪装当前 | 故障标记、最后确认时间、运行操作禁用与恢复 |
| 7 失效退出 | 失效/匿名注销幂等；离线退出本页和恢复后注销 |
| 8 版式 | 一套紧凑内容骨架、统一起点、减少重复介绍 |
| 9 存储边界 | 主机定义/执行与浏览器入口/下载/集合分别说明 |
| 10 缺变量修复 | 汇总、草稿补齐、焦点定位，现有变量保留 |
| 11 孤立问号 | 路径/搜索操作帮助移除，字段提示保留 |
| 12 弹窗焦点 | 取消、Esc、关闭后恢复触发点 |
| 13 浏览器导航 | 深链接、前进/返回及服务滚动位置保留 |
| 14 草稿目录 | 左侧临时项、计数和未保存状态一致 |
| 15 过期反馈 | 草稿丢弃后不再保留“草稿仍保留”等旧通知 |

## 验证方式与边界

`npm run test:portal`构建后运行隔离的真实浏览器回归。测试使用临时目录和模拟Nginx进程信息，不使用用户配置、不执行nginx命令。优先选择本机LAN网卡地址，避免把回环可信来源冒充普通HTTP页面。实际动作使用鼠标命中和滚轮，读取DOM仅用于断言；不通过DOM click绕过裁切。覆盖项目中心1440/1024/390宽度，HTTP1920/1366/1024/390及125%缩放、深色主题，运行状态故障、复制降级、调试隔离、缺变量草稿、浏览器返回和离线/失效退出。截图及结果位于`artifacts/portal-regression/`。

`npm test`包含调试覆盖值和复制结果测试；`npm run test:http`包含匿名/失效会话注销及旧路由兼容测试。完整桌面和既有共享流程仍由`npm run test:electron`、`node scripts/smoke-sharing.mjs`验证。

制作Windows安装包后，`node scripts/smoke-portal.mjs --packaged`使用实际ASAR中的门户资源、服务端及共享模型重复上述交互验证，防止源码通过而包内遗漏。

目标Linux/麒麟桌面、长时间多人并发、系统防火墙和所有浏览器权限策略仍需对应环境验收。回退失败会提供手动复制，不承诺浏览器一定允许写入系统剪贴板。

本次调试值存在覆盖时，重新载入当前接口、切换到其他接口或新建接口会先提示是否放弃这些本页草稿；选择继续编辑会保留，确认放弃会清除覆盖值。切换设计/调试视图或共享服务不会丢弃它们。
