## 开始使用

1. 根据系统选择安装包：Windows 使用 `DevKit_{{VERSION}}_x64-setup.exe`；Linux amd64 / ARM64 使用对应架构的 `.deb`。发行合集目录为 `artifacts/release-{{VERSION}}/`。
2. 启动后在总览中搜索工具名称或用途，或按 `Ctrl/Cmd + K` 打开全局搜索。工具可载入示例、粘贴文本或导入本地文件，处理后复制、导出或继续送入其他工具。
3. 需要管理开发、测试、生产入口时，打开侧栏的“项目中心”，添加项目与配置档案；其他电脑需要访问时，使用顶部工具栏的“局域网共享”统一开放模块和设置权限。
4. 管理其他电脑时，在“共享栏目 → 局域网主机”保存 DevKit 共享或 SSH 连接，并勾选所需栏目。回到服务管理或 Nginx 配置，添加实例时选择本机或已保存的目标主机。浏览远程文件时可直接打开绝对目录，也可逐级浏览。在“局域网共享”开放“局域网主机”后，获准的访客可查看同一份主机清单，并按监控和日志权限查看对应主机的记录。
5. 打开“HTTP 调试”，在“接口项目”中维护项目、目录、接口定义和环境变量，切换接口设计、文档与运行调试。接口目录按拼音或字母排列，搜索时仅显示有匹配接口的目录。支持响应 Schema 校验、OpenAPI/Swagger JSON/YAML 导入导出、Markdown 文档和完整项目备份。原来的“快速请求”保留集合、历史和代码生成流转。全部界面与数据可离线使用，只有点击发送才访问目标服务，详见 [HTTP/API 工作台说明](docs/http-workbench.md)。
6. 点击窗口关闭按钮，选择“退出软件”或“最小化到托盘”，可勾选记住选择；在“偏好设置 → 窗口与托盘”中随时改回每次询问。托盘菜单可打开或退出，真正退出时仍检查未保存草稿。

Windows 解压版需要保留整个应用目录，再运行 `devkit.exe`。Windows 安装包当前未配置代码签名。Linux / 麒麟离线安装、基础库检查和启动排查见 [麒麟 V10 部署说明](docs/kylin-offline-install.md)。

### 经纬度处理

“时间与数值 → 经纬度工具”在同一工具内提供十进制度/度分秒互转、圆心与半径的四方向圆周点计算、混合文本中的度分秒坐标提取。圆周算法可选 WGS84 椭球测地线（默认）或球面大圆；支持单值、坐标对、整列和 CSV/TSV 复制/导出，各页签分别保留参数与结果。

粘贴坐标对“填入经纬字段”及提取后“用作圆心”保留角度原文，只有主动转换才改变表示。结果的十进制度/度分秒旁分别复制对应数值。格式转换不改变坐标基准；圆周方向为起始方位角，正东/正西终点纬度可能变化。文本提取不跨无关段落拼凑坐标，无法确认的片段另列供核对。输入格式、精度、半径及复制边界见 [经纬度工具说明](docs/geographic-coordinates.md)。

### 本地开发诊断与文件分析

在工具目录按名称或英文格式搜索，例如 HAR、Parquet、Source Map 或 MyBatis。双表对账按表头与组合业务键匹配，支持 CSV 和 TSV；重复键会列出记录数。表格结果可以筛选、翻页、展开一行详情，下载保留完整结果。比较类工具分别导入两份文件，再按「开始处理」。

HAR、CPU Profile、Source Map 和构建体积工具还提供「直接分析大文件」入口。单个文件可达 128 MiB，预览前 500 条记录，导出完整报告。Parquet 支持按列与行范围读取，每批最多 100 万个单元格。中文乱码诊断可在 UTF-8、GB18030 和 UTF-16 间转换，导出时另存副本。

文件检查直接读取本地文件。Excel 可切换工作表，分别查看公式缓存和导出数据；ZIP 的第二个归档为可选，选择后可按完整路径核查 CRC 和体积变化。截图对比支持容差、抗锯齿选项与热图；图片压缩可在实际编码结果之间切换并下载。Mermaid、SVG、GeoJSON 和性能图在本机预览。

文件工作台左侧选择或拖入文件、调整参数，右侧查看结果。窗口较窄时，结果排在输入下方。双文件工具支持将两个文件一起拖到第一个入口，也可单独替换对照文件。截图对比和图片压缩支持直接拖动图上的分界线，键盘聚焦后可用方向键微调。

在表格结果中可按任意列的内容筛选。点击第一列的箭头即可在当前行下方展开字段，再点一次收起。横向滚动宽表时，筛选框和分页按钮保留在原位。

在「站点图标包」选择母图并填写应用名称，可即时预览浏览器标签和应用图标。点击「生成图标包」后即可下载 ZIP，其中包含六种尺寸的 PNG、三尺寸 ICO、Web Manifest 和 HTML 引用片段。

现有工具页中展开相应操作即可进行三方合并、生成并预演 JSON Patch、导入 cURL、构造批量 INSERT、计算响应字号、核对目录或比较两个坐标。工具配方可附带输入与期望结果，在指定步骤或最终输出进行回归；正则测试支持保存匹配与替换样例。

在 JSON Patch 面板中，可以对照编辑源 JSON、目标 JSON 和用于预演的文档。切换到“应用已有补丁”后，编辑区显示补丁和应用它的文档。编辑器提供行号与语法高亮，窄屏下按阅读顺序排列。

## 颜色管理

切换配色时可以跟踪同一位置的新色值。清空收藏色需要再次确认，随后可在 12 秒内撤销并恢复原顺序。

取色、格式转换、调色板、渐变、对比度和混色共用当前主颜色及最多 40 个本地收藏色。支持 HEX / HEXA、RGB、HSL 输入，显示 HSV / CMYK 分量，配色可导出 CSS 变量或 JSON，渐变可导出 CSS。

屏幕吸管在运行环境支持时启用；也可使用色板或本地图片取色。图片支持 PNG / JPEG / WebP / BMP，最大 20 MB、2000 万像素，可按坐标取色，不上传图片。颜色换算基于 sRGB，CMYK 不含印刷 ICC 配置；HSL 色阶不保证感知均匀。对比度检查提供 WCAG 2.2 的 AA / AAA 阈值判断。

## 局域网主机

从桌面的“共享栏目”管理远程连接。支持按直连 IPv4 网段发现主机、CSV 或 OpenSSH 配置预览导入、分组、标签、置顶和分步连接诊断。SSH 支持密码、SSH Agent、默认或指定私钥、跳板机及指纹校验。终端支持多会话、重连和 SFTP 文件传输。主机卡片可启用端口监控、打开 Windows 远程桌面或向直连网段发送网络唤醒包。

通过 SSH 集中管理时，DevKit 自动识别 Windows x64、Linux x64 和 Linux ARM64（含兼容的麒麟 ARM64），从中心端离线部署便携 Node.js 和管理程序。优先使用 SFTP，未开放时通过 SSH 命令通道上传。JAR 目标需安装适合该应用的 Java，Nginx 目标需安装 nginx。见 [连接与权限](docs/workspace-sharing.md)。

## Nginx 配置

实例详情顶部用一行显示主机和主配置简称。展开「实例路径」可查看完整路径、Nginx 程序设置和 PID 文件位置。

- **多主机**：添加时选择本机或已连接的远程主机，可浏览远程配置目录。统一进行编辑、新建、备份、检查与运行。开放 Nginx 共享后，授权网页可操作相同的分组实例。
- **多实例与多文件**：Windows / Linux 每个实例均可登记一个主配置及多个附属文件，按 include 递归发现（包括通配符）或手动添加。没有文件时选择“新建配置”，指定目录、主/附属文件名和端口，生成已互相引用的双文件配置及运行目录，创建后直接进入编辑；已有同名配置不会覆盖。导入已有文件时仅登记，不自动改写 include。
- **字段与全文编辑**：默认按 `http` / `server` / `location` 等层级显示字段，提供端口、域名、静态目录、代理目标、请求头、日志、PID 等说明，保留未知指令、重复指令、注释和原有布局。可新增/删除指令或配置块；主文件与附属文件的全文模式均提供 Nginx 语法高亮，区分指令、参数、变量、数字和注释，适配深浅主题，并支持行号、查找与撤销。
- **新手填写提示**：仅在输入字段旁保留“？”，支持悬停、点击和键盘聚焦查看中文用途、示例及路径基准，点击外部或按Esc关闭；操作按钮、配置块标题及汇总说明不再额外显示提示。
- **实例删除**：实例列表和顶部均提供明确的删除入口。有草稿也可发起删除并确认放弃；删除其他实例保留当前草稿，删除当前实例切换相邻项，删除最后一项回到空状态。删除只移除实例记录，保留配置、备份及已有Nginx进程。
- **文件保存与恢复**：配置原地保存，保存前检查内容哈希并备份原文件。备份可与当前配置对比，或载入草稿。应用失败后可先恢复磁盘文件，再确认目标进程并重载。配置须为 UTF-8，保留 BOM 和现有换行。
- **引导与草稿保护**：尚未添加实例时，直接选择“新建配置”或“导入已有文件”，Windows/Linux均支持主文件与多个附属文件。实例表单按基本信息、配置/目录组织，底部操作栏固定；仅实际修改后才提示未保存。取消编辑、关闭应用和重新加载使用统一的主题确认弹窗，“继续编辑”保留输入与服务连接。
- **本机运行控制**：自动检测 PATH / 常见路径，也可指定 nginx 程序与运行目录。启动、重载前执行 `-t`。启停和重载均检查进程身份，发出重载信号后核实工作进程换代并显示确认结果。
- **目录准备与固定操作区**：检查、启动、重载时自动补齐日志/PID父目录、临时及缓存目录，并列出新建结果；不覆盖文件、不伪造配置或证书。桌面和共享网页向下滚动时，仅检查配置、启动、重载、停止和保存文件一行吸顶。筛选后仅剩少量字段时，操作栏仍可稳定吸顶。滚回顶部可查看实例信息和执行详情。
- **Windows / Linux**：共用同一套功能；配置应符合目标系统的路径、模块和权限。可编辑其他系统的文件，运行操作仅对匹配系统启用。每个并行实例需不同 PID 路径和监听端口；进程不会随 DevKit 退出而停止。局域网页面可按授权远程填写实例与主机路径、新建配置、编辑文件和查看日志；所有文件操作均发生在运行 DevKit 的主机，程序检测、检查、启动、停止和重载需另开运行权限。

完整步骤、路径规则、命令和权限排查见 [Nginx 配置说明](docs/nginx.md)。

「接口集合回归」将追加、保存、运行和停止入口放在步骤列表前，可按顺序发送接口，从响应提取变量供后续步骤引用，检查状态与 Schema 并导出报告。快速请求集合每页显示 10 项，搜索覆盖全部请求，明细滚动时仍可操作导入、导出和翻页。接口工作台采用本项目原生组件与主题。方案调研、支持边界见 [API 工作台设计](docs/api-workspace-design.md)，本次新增依赖的许可证见 [API 第三方声明](docs/api-third-party-notices.md)。

## 服务管理

前端开发服务器、API 等可登记在同一列表。“解释器脚本”可选择 Python、Node.js 等解释器和入口文件，工作目录默认取脚本所在目录。在服务的“关联项目”中可新建关联项目，也可查看已有项目、建立或解除关联，网页访客按项目权限操作。

点击“添加服务”，选择主机和启动方式。Java 和 Node.js 路径旁的“查找已安装版本”会列出目标主机上的版本号和程序路径，点击一项即可回填，也可输入绝对路径或点击“手动选文件”。选择 Java JAR 后，可在 Java 程序路径旁点击“检测 Java”，核对所选主机上的版本与可执行文件路径，再设置 JVM 参数和应用参数。npm 项目可为每个服务选择目标主机上的 Node.js 程序，点击“检测 Node.js 和 npm”核对版本及路径，再选择项目目录和启动脚本。检测和启动均使用所选安装，路径留空时按服务环境的 PATH 查找。可执行程序可在路径旁点击“检查可执行文件”，检查目标主机上的文件格式，在 Linux 上还会核对执行权限。Go 编译产物可直接登记。保存后点击启动，运行状态与业务健康独立显示。

更新 JAR、可执行程序或入口脚本时，直接点击服务列表中该实例“停止”旁的“替换服务文件”。确认目标主机和原路径，停止服务后选择新文件。默认备份原文件并在替换后启动，两项均可取消。回退时，在同一弹窗选择“恢复历史备份”，选中目标版本后点击“恢复并启动”。

旧 JAR 的实例 ID、运行记录、日志、守护与自启继续使用。应用按主机分组，桌面和共享网页复用同一份登记。共享设置中勾选“包含 npm、可执行程序与解释器脚本”后，已有编辑和运行授权才扩展至这些服务；独立服务对应 DEVKIT_JAR_BACKEND=true。

从顶栏“配置文件”选择服务后，先核对配置目录，再从文件列表选择要编辑的文件。支持同目录下的 UTF-8 YAML、Properties、JSON、XML、TOML、INI、CONF 和 CFG。底部可预览修改、保存及查看上一版。保存会检查磁盘版本并备份原文件，可把上一版填入编辑器后再保存。共享访客需要服务编辑权限。

提供 silent、file、console 三种启动模式。console 在工具内显示实时 UTF-8 标准输出与错误，支持搜索、复制、清空本页、暂停滚动及行输入/EOF；多人同时查看，有运行权限的客户端一次只有一个可取得输入控制权，断线后租约到期。关闭控制台或共享网页不停止应用，重新打开可查看仍保留的输出；console 仅保留有界内存输出，不写标准输出日志文件，不提供 PTY 或系统 Shell。

PID 和日志放在服务工作目录；JAR 使用同级目录，默认 `<JAR名>.pid`、`<JAR名>.log`，可改为脚本的 `app.pid` / `app.log`；多应用禁止文件冲突。独立守护接收标准输出和错误，默认按 10 MB 轮转、归档保留 7 天且最多 10 份；仅清理本工具生成的归档。支持静默模式及最近 128 KB 日志定时查看。Linux 先 TERM 等待退出，超时可单独强制终止；Windows 终止无法保证 Java 关闭钩子执行。

可配置 HTTP(S) 预期状态码或 TCP 连接检查、检测间隔、超时、启动宽限与连续失败阈值，单独展示业务健康，不把进程存活当作就绪；健康失败不自动重启。崩溃自动重启默认关闭，启用后按指数退避、次数上限和稳定时间重置执行，手动停止取消重试，正常退出不拉起。退出 DevKit 后守护仍继续健康检测、轮转与重试。

“系统自启”支持 Windows 任务计划的当前用户登录 / 开机触发，以及 Linux systemd 图形会话登录 / 开机 linger。注册表保存在实例所属主机的配置目录中。服务管理可独立开放局域网共享，查看、编辑与运行权限分开；只读访问不返回环境变量值与启动参数，输入及系统自启需运行授权。网页可填写目标主机路径并浏览已保存的远程主机目录，独立 Node 服务同样支持。Java 安装、旧脚本 PID 兼容、守护生命周期和平台限制见 [服务管理说明](docs/jar-manager.md)。

## 日志中心

在关联应用服务的监控故障时间线上打开「查看故障前后 5 分钟日志」，可按来源和时间查看已登记文件中的匹配行。

宽屏可拖动两栏之间的分隔条，聚焦后用左右方向键调宽，双击或按 Home 恢复默认宽度。在窄屏的来源列表顶部下拉可以刷新来源。

按主机聚合本机、SSH 及 DevKit 共享目标上的已登记服务的文件日志、console 输出及 Nginx 文件日志，可从实例直达对应来源。最多四窗独立增量追踪，窄屏用标签切换当前日志流，支持关键词/正则与级别筛选、自动滚动、复制及有界导出。主机默认在发送前脱敏。访客在日志中心、服务管理和 Nginx 页面读取日志时统一核对日志类别授权，远程 DevKit 还需目标端授权。详见[日志中心说明](docs/log-center.md)。

桌面从侧栏“共享栏目”打开栏目列表，收起侧栏时顶部也提供“共享栏目”。点击“排序”，拖动栏目左侧手柄或直接选择目标位置，也可用上下箭头微调或恢复默认顺序。“保存顺序”会同步更新两个入口，顺序随本机偏好保存和导入导出。共享网页的侧栏和手机导航也可排序，保存到当前浏览器。网页侧栏随窗口宽度调整，为滚动条预留空间。只有栏目列表随滚轮移动，排序入口和共享主机地址固定在列表上下方。共享栏目可从实例定位主机和日志、从监控回看来源、在 HTTP 与模拟接口间创建草稿，也可在文件共享和待办之间打开引用。画板邀请可以填入快传。目标栏目未共享或缺少权限时，点击入口会在原处显示气泡。完整对应关系见[共享网页版说明](docs/portal-browser.md)。顶部广播图标显示发布状态并打开发布设置。共享设置显示监听地址、开放栏目及各访客的生效权限；网页从“主机与权限”查看当前主机及权限，运行模式与主题统一放入“外观”。两端均可用 Ctrl+K 搜索栏目、实例、接口、项目及监控，并复制可直达资源的链接。

## 监控中心

HTTPS 入口显示证书到期时间，可在 Webhook 设置中启用剩余 30 天和 7 天的提醒。

最近的检测记录会按时间段显示成功与失败次数。空时间段显示短横线。新增或编辑监控时，地址、端口和预期状态码的错误显示在对应字段下。

监控中心由主机定时执行 HTTP(S) 或 TCP 检测，可填写地址，或关联项目入口、服务健康检查和局域网主机端口。支持 10 秒至 24 小时间隔、1–60 秒超时、连续失败确认、故障与恢复记录、维护窗口及暂停/启用。异常、恢复和维护窗口显示在同一条时间线上。HTTP 使用 GET、校验证书并最多跟随 5 次重定向，仅读取响应头，以配置的预期状态码判定正常；TCP 仅判断能否连接。

每项最多保留最近 1,440 次且不超过 7 天的样本，以及最近 100 次故障。界面展示最近 24 小时已保留样本的成功比例、平均响应耗时及最近 60 次趋势；不是按持续时间计算的 SLA。配置保存在 `configs/monitor/monitors.json`。桌面切页、托盘和关闭共享网页后仍检测，退出主机应用或独立 Node 服务后停止；重启不补造离线样本，过期状态显示待检测。

远程服务的 HTTP/TCP 健康检查由目标主机发起，详情显示执行主机。可选 Webhook 在确认故障和恢复时发送 JSON POST，暂时性失败自动重试。可独立开放共享查看，编辑与运行分别授权。使用范围、存储与权限见 [监控中心说明](docs/monitor-center.md)。

## 团队知识库

从共享栏目打开「团队知识库」，从空白页编写 Markdown 文档，或选用部署、排障、交接模板。可按目录、项目和标签整理，恢复本机草稿，跨栏目批量插入资源和文档链接，通过正文搜索与章节链接定位内容。支持历史版本预览与恢复。在部署步骤中可插入具体 应用服务、Nginx 实例的链接，也可从实例详情反查引用它的手册。桌面和共享网页使用主机上的同一份资料。开启栏目后，获准访客可以阅读全部文档与历史版本，编辑权限单独授予。详见[团队知识库说明](docs/knowledge-base.md)。

## 项目中心

在项目编辑窗口展开「关联运维资源」，分别选择 API 项目、应用服务、Nginx 和监控。点击项目卡片顶部的「运维总览」，可查看入口、实例状态、最近故障及日志入口。

对比窗口显示已选档案及数量，最多选四份。导入时可逐步核对读取、预览、备份并写入和完成状态。

项目中心按独立档案维护不同方案的项目入口，桌面与局域网网页共用同一份主机数据。

宽屏的档案区与项目区可分别滚动，也可聚焦后用键盘浏览。窄屏按顺序展示档案操作、筛选和项目列表，在同一区域内连续滚动。

- **项目与档案**：每个配置档案独立拥有项目与变量；项目维护名称、档案内唯一编码、分组、说明、HTTP(S) 地址模板、查询参数和启停状态。新建档案为空，复制档案产生独立副本；增删改仅影响所属档案。切换档案只影响当前使用者。
- **管理与预览**：支持搜索、分组、排序、紧凑卡片 / 列表、复制项目 / 档案，以及图标与文字统一对齐的批量操作栏，支持勾选后的批量启停、批量删除（确认时列出筛选外勾选项，删除前自动备份）。项目卡片直接提供删除入口；编辑时展示 URL 组成及当前档案的解析结果，有修改时提供草稿退出保护。
- **导入导出与恢复**：支持 JSON 导出、导入影响预览、合并或替换；保存时检查版本冲突。自动保留最近 30 份快照，支持命名备份、恢复预览，导入和恢复前自动备份。
- **对比方案**：在“参与对比的档案”中选择 2–4 个档案，按项目编码对齐并标记缺少的项目，比较完整配置、最终入口与变量。桌面并排对照，窄屏按差异逐项列出各档案的值。使用结果上方的“只看差异”筛选，可导出 JSON 报告。
- **手动探活**：项目卡片/列表提供单项“探活”，当前配置提供“全部探活”（包含筛选外项目），也可检测勾选项。停用项目跳过，逐项展示正常/异常、状态码、耗时及检测时间，并汇总进度；结果仅在当前页面临时保留，不自动轮询。请求由主机发起，启停只控制入口状态，不启动或停止系统服务。
- **局域网访问**：从顶部“局域网共享”统一设置地址、访问口令和访客权限。各服务可独立开放，首次不预选。“局域网主机”可分别授予档案管理、诊断、SSH 终端、SFTP、发现、唤醒与远程桌面权限。配置 `guacd` 后，获准的访客可在共享网页内直接连接远程桌面。已保存的连接凭据由共享主机加密保存。详见 [共享工作台](docs/workspace-sharing.md)。

### 配置保存与迁移

| 运行方式 | 默认配置位置 |
| --- | --- |
| Windows 安装版 / 解压版 | `devkit.exe` 同级的 `configs/` |
| Linux 安装版 | `/opt/devkit/configs/` |
| 独立 Node 服务 | 解压根目录的 `configs/`，与 `server/` 同级 |
| 源码桌面运行 | 仓库根目录的 `configs/` |

桌面顶栏可打开“配置文件”和“局域网共享”。升级时会将旧目录中的已知文件自动分组，遇到同名冲突会提示核对并保留两份文件。项目与快照放在 `configs/projects/`，共享权限、Git 仓库登记、审计和链接放在 `configs/sharing/`，知识库和待办放在 `configs/planning/`。每个档案对应一个 `profile-<编码 ID>.json`，独立保存项目与变量；`projects.json` 保存索引、版本与快照，共享设置及加盐口令哈希另存。旧数据自动展开为独立档案并保留原始备份；API 项目、环境和上次保存快照位于 `configs/http/api-workspace.json`，整目录复制时一起迁移；桌面 Nginx 实例注册表和原文件备份位于 `configs/nginx/`，实际配置文件仍在原路径。首次启动会在新位置无数据时迁入旧版项目配置并保留原件；已有新配置优先，升级和卸载保留配置目录。

迁移时关闭来源与目标应用 / 服务，备份目标配置后，复制整个 `configs` 到新安装目录并确保普通用户有写入权限。只导出项目 JSON 不会包含共享口令和历史快照。两边数据需要合并时使用界面的导入预览。

### 独立服务部署

适合常驻主机：解压 `DevKit_ProjectCenter_{{VERSION}}_node24.zip`，**服务端准备 Node.js 24+**，无需 `npm install`；浏览器客户端无需安装运行时。首次启动需提供口令。

Windows PowerShell：

```powershell
$env:DEVKIT_PROJECT_PASSWORD='替换为独立访问口令'
$env:DEVKIT_SHARE_PROJECTS='true'
node server/start.mjs
```

Linux：

```sh
DEVKIT_PROJECT_PASSWORD='替换为独立访问口令' DEVKIT_SHARE_PROJECTS=true node server/start.mjs
```

默认监听 `0.0.0.0:8765`。首次通过 `DEVKIT_SHARE_*` 选择至少一个服务，例如用 `DEVKIT_SHARE_LAN_HOSTS=true` 开放主机清单。编辑和执行另行授权。后续复用已保存设置，明确的环境变量逐项覆盖。主机可配置 HTTPS 证书、独立访客及访问审计。同一配置目录由一个主机进程使用。变量、证书及会话撤销见 [共享工作台](docs/workspace-sharing.md)。

## 本机文件共享管理

在共享清单中查看运行状态与端口，选中共享后管理范围、复制指定网卡的链接或打开下载页。下载页支持筛选文件名和下载文件夹 ZIP。勾选发布并在“局域网共享”中开放栏目，获准访客即可登录，在共享列表直接进入下载页。[配置与访问方式](docs/workspace-sharing.md#本机文件共享管理)

## Git 仓库管理

在「共享栏目 → Git 仓库管理」登记工作树或从桌面克隆仓库。在文件行点击 ＋／－ 可暂存或取消暂存，也可勾选多个文件一次操作。差异预览支持按块暂存。文件列表前的操作栏可打开提交窗口或推送预览。工作区与暂存区各按 50 个文件分页，跨页勾选后可一次操作。提交图按父提交连线，可跨页追踪分叉、合并和分支标签，点选节点查看差异。克隆与权限设置也在弹窗中完成。首次推送可建立上游。分支总览与提交、推送控件随当前主题和明暗模式显示。两端均可比较与合并分支、处理冲突、检索文件历史和比较提交。新登记仓库发布时默认只共享提交历史，主机可在「仓库访问权限」弹窗逐仓库、逐访客授权。详见[使用与设计说明](docs/git-workspace.md)。

## 待办清单

大纲支持展开验收子项并定位原文，也可前后浏览续做点；浏览不会修改任务状态。填写等待对象时可选用清单里出现过的联系人。

待办清单采用 Todo+ 风格的纯文本编辑。用冒号分组、用 `☐` 写任务。在任务或续做点下可添加多层子任务，单独跟踪和完成。续做点记录做到哪里、下次从哪接上。编辑器随光标提供验收条件、续做点等常用操作，“扩展语法”可写入自定义视图、工作台引用、回访日期、前置依赖、周期规则和分组默认标签。阅读时显示可点击的方框和引用、中文标签与验收进度，编辑时可查看源码。桌面端和局域网页均支持导入文本清单和导出 `.todo`。可逐份发布，选中后可在正文标题旁删除。局域网访客获编辑权限后可导入新清单或删除已发布清单，只读访客可导出已发布清单。[待办清单](docs/project-center.md#待办清单)

## 快传、接口模拟与截图协作

快传主机暂存支持暂停和续传。同一标签页在 10 分钟内使用相同文件、有效期和取件密码再次发送，会从主机已确认的位置继续。主机重启会清除尚未完成的上传。

发布带取件密码的文件、文字或链接后，可在发布端的收件箱点「查看我的取件密码」，核对后点「隐藏取件密码」。接收方继续用原来的方式凭密码取件。

快传列出本批文件大小和发送方式，失败时保留未发送项目。主机存储条按已暂存文件的实际字节分布。截图白板可用拖动或方向键对照原图与标注，新建空白画板可选横屏、方形或竖屏。

快传在窄屏上可切换「收件箱」和「发送内容」，在取件密码下方直接选择有效期。手机上编辑 HTTP 接口时，参数按条排列。白板打开后，可通过「画板库」切换或新建画板，从绘图工具栏选择矩形或椭圆。

模拟接口优先显示响应编辑器、预览和保存。选择「自动生成」可套用订单、用户或商品模板，设置每次调用生成 1 至 100 条记录。在「导入与数据集」导入 HTTP 接口时，可直接按响应 Schema 生成数据。在「场景设置」配置路径、查询、请求头和正文字段条件；「调用与记录」显示实际耗时和命中原因，可将请求带入 HTTP 调试。多个接口可填写相同项目名称，共用一个基础地址。新建项目数据集可用同一组记录联调列表、详情与修改。详见[模拟接口与项目数据集](docs/workspace-sharing.md#模拟接口与项目数据集)。

桌面与共享网页使用紧凑的栏目标题。共享网页将快传、模拟接口和白板的「邀请设备」放在「主机与权限」旁。文本工具的操作提示放在「使用提示与边界」，文件工具先展示选取与处理操作。经纬度工具直接显示坐标输入、转换和结果，精度与导出格式可按需展开。监控计数合并为状态栏，知识库可展开项目与标签筛选；偏好设置直接显示明暗模式和密度，展开「主题风格」查看完整样式。

在顶栏「局域网共享」中选择栏目、局域网监听地址和访客权限。另一台电脑或手机用浏览器打开邀请链接，也可以扫码加入。

- **局域网快传**支持电脑与电脑、手机与电脑之间双向收发。发送、暂停入口位于待发送文件清单之前，清单每页显示 30 项。在桌面顶栏的「局域网共享」中展开「快速链接设置」，填写空闲端口并保存。收件人只需在浏览器输入主机的局域网 IP 和端口（如 `http://192.168.1.20:8780`），即可进入同一个快传收件箱，无需工作台口令或访客账号。已有长链接可在设置中勾选「为旧端口开启短地址」后保存。文件默认使用「在线直传」，发送方保持页面在线，接收方输入正确密码后点击「保存直传文件」。需要发送方离线后仍可取件，或要发送文字、链接时，手动选择「主机暂存」。暂存文件保存在主机数据目录的 `collaboration/` 下，可设置取件密码和有效期，移除或到期清理时释放空间。
- **接口模拟服务**可从 HTTP 工作台导入响应示例，在局域网地址上切换状态码、响应正文与延迟。应用和脚本可直接使用已发布的调用地址。
- **截图协作白板**支持粘贴截图或创建空白板。多台设备可在同一张板上画箭头、圈选和写字，再导出包含全部已同步标注的 PNG。

[权限、容量与使用说明](docs/workspace-sharing.md#快传接口模拟与截图协作)

## 开发与打包

在 Windows 上双击仓库根目录的 [`start-preview.cmd`](start-preview.cmd)，即可使用当前源码启动桌面预览，验证待办清单、文件共享和局域网功能。启动需要 Node.js 24+ 和 `tar`，依赖缺失时脚本会自动安装。预览窗口标题为“DevKit · 源码预览”，桌面偏好和浏览器数据独立保存在 `artifacts/desktop-preview-profile/`，项目和共享配置沿用仓库的 `configs/`。源码修改后，彻底退出预览窗口再双击脚本即可加载新版本，无需生成安装包。

### GitHub 正式发行

正式发行统一由 GitHub Actions 构建、校验和发布。提交并推送 `main` 上的版本更新后，推送与 `package.json` 版本一致的附注标签（例如 `1.23.0`）。[GitHub Actions](https://github.com/suyh1/DevKit/actions/workflows/build.yml)

每次升版时，在 `docs/releases/<版本号>.md` 用中文写明使用者能看到的变化和新功能的入口，与版本号一起提交。推送标签前可用 `node scripts/generate-release-notes.mjs <标签>` 预览。GitHub Actions 从标签对应的提交读取这份说明，缺少文件或中文正文时会停止发布。Release 末尾附有与上一已发布正式版的完整变更对比链接。

正式发行目标为 **5 分钟以内**，从版本标签触发 Actions 开始计时，直到 GitHub Release 的安装包可下载。排查耗时时可在 Actions 查看各阶段记录。

普通提交和拉取请求只运行一轮无窗口检查和前端构建。推送版本标签后，工作流额外构建并校验 Windows x64、Linux amd64、Linux ARM64 安装包及 Node.js 24 独立服务 ZIP，全部通过后自动发布。安装包和 SHA-256 校验清单可在 [GitHub Releases](https://github.com/suyh1/DevKit/releases) 下载。

发行时，无窗口检查与前端构建并行，各平台复用同一份前端产物。Linux 安装包使用兼容 `dpkg` 的快速 gzip 压缩，Windows 安装包使用 NSIS 的 ZIP 压缩，云端会并行准备 Windows 发行所需的运行时和构建依赖。下载文件可能因快速压缩而略大。

手动运行工作流可生成供验证的构建产物。需要回归桌面窗口或平台相关功能时，可勾选 `full_regression`；常规构建和正式发行默认关闭此选项。本地验证待办和共享可用 `npm run test:electron -- --sharing-settings-only`。

### 开发与构建命令

构建机使用 Node.js 24 和 `tar`，Linux 构建机还需 `unzip`。制作 `.deb` 或独立服务 ZIP 需 Python 3.10+。首次构建会获取并校验 Electron 和 SSH 目标机用的便携 Node.js，构建完成后可在离线环境部署。可提供本地官方 Node.js 发布归档，通过 `DEVKIT_SSH_NODE_DIST_DIR` 指定所在目录。

```sh
npm ci
npm run dev       # 浏览器开发
npm run desktop   # 构建后启动 Electron
```

桌面运行时当前使用 Electron {{ELECTRON_VERSION}}。安装包包含 Chromium，Linux 包不添加系统软件源、不替换系统库；依赖以 `.deb` 控制文件为准。麒麟实际安装和启动需要在目标系统验收。

{{PACKAGE_TABLE}}

`bundle:all` 在 Windows 构建机依次制作三平台安装包，汇总 `SHA256SUMS`、`release.json` 和当前 README；独立服务 ZIP 使用单独的打包命令。仅汇总已经构建的安装包可运行：

```sh
node scripts/package-all.mjs --collect-only
npm run verify:release
```

制作安装包时校验实际 ASAR 内容并生成构建凭据。汇总时用当前构建内容比对凭据，同时核对版本、架构和安装包校验值，拒绝过期产物。Python 路径可用 `DEVKIT_PYTHON` 指定。Windows 打包显式设置 `publish: 'never'`。GitHub Actions 的发布任务使用仓库提供的 `GITHUB_TOKEN` 上传已校验的文件。提交旁的红叉表示自动检查失败，可在 Actions 中查看具体步骤。Windows Nginx 测试统一使用真实路径，兼容临时目录的 8.3 短路径别名。

### 本地产物保留

打包成功后按版本号保留 `artifacts/` 内最新两个已有产物的版本，包含安装包、独立服务 ZIP、解压版及配套校验与文档。单平台命令仍写入架构目录，汇总后可直接使用对应的 `release-版本` 目录，已确认一致的重复安装包会被清理。桌面安装包构建完成后会移除本次临时运行时与暂存目录。

停止使用本地构建和测试目录后，可运行 `npm run clean:artifacts` 清理历史临时目录和重复文件。使用 `npm run clean:artifacts -- --dry-run` 可预览。清理保留未知文件及解压运行时产生的配置目录。

### README 自动维护

**每次打包都会先根据当前功能生成根目录 README.md，失败时停止打包。** Windows、Linux、麒麟别名、解压版、合集（含 `--collect-only`）及独立服务 ZIP 均覆盖；直接运行打包脚本同样生效。安装包、输出目录、解压版、发行合集和独立服务 ZIP 会附带当前 README 及其链接的专题文档。

```sh
npm run docs:update   # 手动同步 README
npm run docs:check    # 只检查一致性，过期时返回失败
npm run test:docs     # 验证自动更新逻辑
```

维护来源：

- `src/tools.ts` 及其引用的工具模块：自动读取实际工具名称和功能说明，新增、删除、重命名或修改说明均同步到清单。
- `src/catalog.ts`：自动读取分类和工具顺序；工具遗漏、重复或引用失效会阻止生成。
- `package.json`、`scripts/release-integrity.mjs`、`src/workbench.ts`：自动读取版本、Electron 版本、发行文件名、打包命令和任务数量限制。
- `docs/README.template.md`：维护工作台、项目中心、部署和使用边界等说明。相关功能改变时同步修改模板及专题文档，再生成 README。

生成不依赖在线 AI 或网络；内容相同不会重复写入，也不写入构建时间。请修改上述来源，避免直接编辑会被重新生成的根目录 README。

## 验证与使用边界

```sh
npm run docs:check
npm run test:docs
npm test
npm run test:desktop
npm run test:projects
npm run test:git
npm run test:release
npm run test:electron
npm run build
python scripts/test-deb-packaging.py
```

生成的 Java 代码可额外用 JDK 17+ 验证：`npm run test:java`，也可传入 `javac` 路径。桌面集成测试覆盖本地协议、Worker、沙箱及原生保存桥接；保存对话框的选择使用测试桩。真实安装、目标 Linux / 麒麟启动及跨电脑网络访问需在对应环境确认。

- 文本工具在独立 Worker 中执行；正则超过 3 秒、其他任务超过 10 秒会终止。通用输入上限为 2,000,000 个 UTF-16 单元，输出为 4,000,000 个；部分工具有更小限制，具体见界面说明。
- JSON 格式化保留数字原文与重复键。选择“字符串 → JSON”可解开一层转义，例如将 `"{\"id\":1}"` 还原为 `{"id":1}` 并按所选缩进显示。选择“JSON → 字符串”可将整份 JSON 原文编码为带双引号的字符串。JSON / YAML 转换拒绝重复键等不兼容结构，转换不保留注释和排版。CSV 默认保留字符串，并对导出中的表格公式字符串转义。
- JSON 转类型按样本推断；类型转 JSON 按声明生成示例，不执行源码，也不还原真实数据。详见 [类型转换说明](docs/type-conversion.md)。
- SQL / 代码工具仅格式化或生成代码，HTTP 工具不发送请求，Cron 只预览 UTC 时间，JWT 仅解码、不验证签名。前后端工具的具体支持范围见 [开发工具说明](docs/developer-tools.md)。
- 工作区、项目导出和配置文件包含明文业务数据，应按实际内容保管；任务内容不会自动持久化，主动复制、导出或共享由用户决定。
