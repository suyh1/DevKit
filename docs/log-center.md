# 日志中心

日志中心聚合已登记的后端服务文件日志、后端服务 console 模式的标准输出/错误，以及 Nginx 生效配置中明确指定的文件日志。它与其他工作台平级，桌面使用左侧入口，共享网页使用侧栏；窄屏从顶部的菜单按钮打开栏目导航，支持键盘切换及 Esc 关闭。

## 选择与追踪

1. 先在后端管理登记应用，或在 Nginx 登记配置。后端服务的 silent 模式不产生可读取的标准输出日志，不列入来源；应用自行写入的其他文件不在本版来源范围内。
2. 打开“日志中心”，用主机下拉框筛选来源，可跨主机选择最多四个来源。共享工作台的主机卡片可直接筛选该主机的来源。后端服务和 Nginx 实例的“日志中心”按钮可直接选中该实例的来源。可使用 SSH 或 DevKit 共享目标，连接失败会显示所属主机。Nginx 静态文件日志来自生效配置。
3. 每个窗口单独增量读取，正常模式间隔两秒，性能模式间隔六秒。慢速或暂时断开的来源只影响自己的窗口。自动滚动可按窗口独立关闭。“暂停接收”暂停本页读取，回到栏目后可从保留的游标继续。

窄屏默认展示一条日志流，从日志窗上方切换已选来源；切换不会中断其他来源的追踪。

来源列表显示文件路径摘要，展开可查看完整路径。新建主机需要局域网主机编辑权限；添加后端服务或 Nginx 来源需要对应栏目的编辑权限和相应日志类别的读取权限。访客可展开「来源管理权限」查看受限原因。

桌面宽度下使用并排/四窗网格，来源列表与各日志窗分别滚动；较窄桌面改为单列窗口，移动端纵向排列。清空显示只清空本页缓存并保留游标；关闭来源后重新选择，会重新读取来源的有界近期内容。

文件首次读取最近128 KiB，之后每次最多64 KiB。字节游标会核对文件身份及已读边界内容，检测重命名轮转、同文件截断/重写；检测到变更时开始新输出段并提示。跨读取边界的UTF-8字符留待下一次补齐；其他编码按UTF-8解码，可能显示替换字符。单窗最多保留256 Ki字符，较早内容会丢弃。

轮转后的旧文件不会自动并入当前窗口；两次读取之间被完全替换或超出缓冲的内容可能遗漏。console输出使用现有后端服务守护的内存缓冲与运行代次，主机重启或缓冲溢出时不能恢复全部历史。日志中心不会另建采集库、修改原日志、启动应用或取得控制台输入权。

## 筛选、脱敏与导出

- 关键词和正则均只筛选本页已经载入的日志行；ERROR/FATAL、WARN、INFO、DEBUG基于单行中的级别单词匹配，多行堆栈的续行可能被筛掉，不是结构化日志分析。
- 正则在独立Worker执行，750毫秒内未完成会终止并显示错误，避免阻塞页面与主机；可清空或简化表达式后重试。
- 默认“主机脱敏”会在响应发出前遮盖常见认证头、Cookie、Bearer 令牌及 password、secret、token、api_key 等字段值。部分跨增量边界的不完整行会隐藏。规则覆盖常见格式，业务中自定义的敏感字段仍需由应用控制。关闭脱敏需要原始日志权限，切换时会重新读取窗口内容。
- 复制按钮复制当前窗口筛选后的显示内容；导出按钮重新读取该来源的有界近期内容，不应用关键词或级别筛选，并遵循当前脱敏开关。文件导出最多最近1 MiB，console导出最多16页（每页65,536 UTF-16单元）的现有内存输出，不等同于全量历史。
- 读取失败会在对应窗口标出，并提示上次内容可能过期。本机与远程请求各有四个并发名额，繁忙时对应窗口在后续轮询重试。

## 共享与独立服务

“局域网共享”中单独开放日志中心；升级旧配置时默认关闭。日志分类和导出分别授权，可以只开放日志中心而不开放后端管理或 Nginx 配置页面。未勾选任何日志分类时仅能打开空的中心页面。

| 授权 | 能力 |
| --- | --- |
| 读取后端日志与控制台输出 | 读取已登记应用的文件日志与内存输出，不含环境档案、启动参数、控制台输入或进程控制 |
| 读取 Nginx 日志 | 只读取已登记实例生效配置中的文件日志，不含配置编辑、重载或启动 |
| 导出日志 | 导出已获分类授权的来源，不扩展来源范围 |
| 允许读取原始日志 | 可主动关闭主机脱敏，仍受各分类与导出权限限制 |

读取按来源 ID 重新核对权限。后端管理页面的文件日志和控制台输出、Nginx 原页面的日志都使用相同类别授权。撤销某类授权后，该类内容在日志中心和对应原页面都会停止提供。经 DevKit 共享连接时，读取、导出与原始日志权限同时受当前主机和目标 DevKit 限制。独立服务可用 `DEVKIT_LOGS_RAW=true` 授予原始日志权限。

独立Node服务支持：`DEVKIT_SHARE_LOGS=true`开放中心、`DEVKIT_LOGS_JAR=true`授权后端日志、`DEVKIT_LOGS_NGINX=true`授权Nginx日志、`DEVKIT_LOGS_EXPORT=true`授权导出。无需npm依赖；程序路径、配置和日志均属于服务主机。来源沿用 `configs/jar/`、`configs/nginx/` 的登记；本中心不保存额外日志副本，来源选择/筛选内容仅保留在本次页面内存。

## 设计对标与验证

对比[Dozzle](https://github.com/amir20/dozzle)（MIT，约14.8k stars，Go/Vue实时容器日志、多窗查看、不存储历史）与[lnav](https://github.com/tstack/lnav)（BSD-2-Clause，约10.8k，原生终端日志分析）。借鉴实时多窗及有界读取，复用现有Node/React与后端服务/Nginx注册表；不复制代码，不引入Docker、Go或原生终端依赖。

后端验证：`npm run test:logs`。构建后真实桌面与共享验证：`node scripts/smoke-desktop.mjs --logs-only`，覆盖轮转、拆分UTF-8、暂停/清空、正则超时、脱敏、导出权限、四窗与移动菜单。

在宽屏来源栏右侧拖动分隔条可调整宽度，左右方向键逐步调整，Home 或双击恢复默认宽度。窄屏在来源列表顶部向下拉动、松开后刷新目录；暂停接收时仍可使用“刷新来源”。

## 查看监控故障附近的日志

在关联后端服务的监控事件旁打开「查看故障前后 5 分钟日志」。查询读取当前已登记文件最后 4 MiB，返回最多 128 Ki 字符的匹配内容。支持行首 ISO 日期与常见 Java 时间戳，堆栈续行归到前一个时间戳。无时区时间按日志主机本地时区解释。结果默认经过主机脱敏。已轮转归档、控制台模式和超出扫描范围的历史需要另行查看原始日志。
