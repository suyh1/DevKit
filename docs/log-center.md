# 日志中心

日志中心聚合已登记的 JAR 文件日志、JAR console 模式的标准输出/错误，以及 Nginx 生效配置中明确指定的文件日志。它与其他工作台平级，桌面使用左侧入口，共享网页使用侧栏；窄屏从顶部的菜单按钮打开栏目导航，支持键盘切换及 Esc 关闭。

## 选择与追踪

1. 先在 JAR 管理登记应用，或在 Nginx 登记配置。JAR 的 silent 模式不产生可读取的标准输出日志，不列入来源；应用自行写入的其他文件不在本版来源范围内。
2. 打开“日志中心”，点击“刷新来源”，搜索名称或路径，勾选最多四个来源。Nginx 动态变量、syslog、stderr、memory 等非静态文件日志不列入来源；配置扫描失败时会显示来源提示。
3. 页面每两秒增量读取。自动滚动可按窗口独立关闭；“暂停接收”停止本页面读取，目标应用和其他查看者不受影响。关闭栏目后停止读取，回到栏目后从保留的游标继续。

桌面宽度下使用并排/四窗网格，来源列表与各日志窗分别滚动；较窄桌面改为单列窗口，移动端纵向排列。清空显示只清空本页缓存并保留游标；关闭来源后重新选择，会重新读取来源的有界近期内容。

文件首次读取最近128 KiB，之后每次最多64 KiB。字节游标会核对文件身份及已读边界内容，检测重命名轮转、同文件截断/重写；检测到变更时开始新输出段并提示。跨读取边界的UTF-8字符留待下一次补齐；其他编码按UTF-8解码，可能显示替换字符。单窗最多保留256 Ki字符，较早内容会丢弃。

轮转后的旧文件不会自动并入当前窗口；两次读取之间被完全替换或超出缓冲的内容可能遗漏。console输出使用现有JAR守护的内存缓冲与运行代次，主机重启或缓冲溢出时不能恢复全部历史。日志中心不会另建采集库、修改原日志、启动应用或取得控制台输入权。

## 筛选、脱敏与导出

- 关键词和正则均只筛选本页已经载入的日志行；ERROR/FATAL、WARN、INFO、DEBUG基于单行中的级别单词匹配，多行堆栈的续行可能被筛掉，不是结构化日志分析。
- 正则在独立Worker执行，750毫秒内未完成会终止并显示错误，避免阻塞页面与主机；可清空或简化表达式后重试。
- 默认“显示脱敏”会遮盖常见Bearer值及password、passwd、secret、token、api_key等键后的值。它仅处理显示、复制与下载文本，不能识别所有秘密，不改变网络响应和原文件。共享日志本身应只授予可信人员。
- 复制按钮复制当前窗口筛选后的显示内容；导出按钮重新读取该来源的有界近期内容，不应用关键词或级别筛选，并遵循当前脱敏开关。文件导出最多最近1 MiB，console导出最多16页（每页65,536 UTF-16单元）的现有内存输出，不等同于全量历史。
- 读取失败会保留上次显示内容并明确标记可能过期；各来源互不影响。主机同时最多处理四个日志请求，繁忙时页面提示并在后续轮询重试。

## 共享与独立服务

“局域网共享”中单独开放日志中心；升级旧配置时默认关闭。日志分类和导出分别授权，可以只开放日志中心而不开放JAR/Nginx管理页面。未勾选任何日志分类时仅能打开空的中心页面。

| 授权 | 能力 |
| --- | --- |
| 读取 JAR 日志与控制台输出 | 读取已登记应用的文件日志与内存输出，不含环境档案、启动参数、控制台输入或进程控制 |
| 读取 Nginx 日志 | 只读取已登记实例生效配置中的文件日志，不含配置编辑、重载或启动 |
| 导出日志 | 导出已获分类授权的来源，不扩展来源范围 |

每次请求重新发现允许来源，客户端仅提交来源ID，不能用路径参数读取任意主机文件。撤销分类或移除来源后，后续读取被拒绝；已经传给访问者的内容无法撤回。关闭服务会清除其权限。

独立Node服务支持：`DEVKIT_SHARE_LOGS=true`开放中心、`DEVKIT_LOGS_JAR=true`授权JAR日志、`DEVKIT_LOGS_NGINX=true`授权Nginx日志、`DEVKIT_LOGS_EXPORT=true`授权导出。无需npm依赖；程序路径、配置和日志均属于服务主机。来源沿用 `configs/jar/`、`configs/nginx/` 的登记；本中心不保存额外日志副本，来源选择/筛选内容仅保留在本次页面内存。

## 设计对标与验证

对比[Dozzle](https://github.com/amir20/dozzle)（MIT，约14.8k stars，Go/Vue实时容器日志、多窗查看、不存储历史）与[lnav](https://github.com/tstack/lnav)（BSD-2-Clause，约10.8k，原生终端日志分析）。借鉴实时多窗及有界读取，复用现有Node/React与JAR/Nginx注册表；不复制代码，不引入Docker、Go或原生终端依赖。

后端验证：`npm run test:logs`。构建后真实桌面与共享验证：`node scripts/smoke-desktop.mjs --logs-only`，覆盖轮转、拆分UTF-8、暂停/清空、正则超时、脱敏、导出权限、四窗与移动菜单。
