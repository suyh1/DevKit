# 工作空间视觉与交互

弹窗、导航、折叠、HTTP 状态、列表、颜色、拖入和骨架等 16 项过渡共用 `Motion.tsx`、`motion-primitives.ts` 与 `motion.css`。退场保留节点，胶囊按真实尺寸弹簧移动，模式切换保留编辑器，复制与异步反馈由实际结果驱动；具体覆盖、技能规范与兼容性见 [界面动效说明](ui-motion.md)。

工作台浅色模式采用灰白与蓝色，深色模式采用「石墨灰 + 雾蓝」。两种模式共用本地字体、Lucide 图标、布局与交互。侧栏和顶部导航悬浮于页面背景之上，工具任务继续保存在原有多任务工作区中。

## 浅色主题

- 页面背景 #F5F6F8、面板 #FFFFFF、输入区 #F0F2F5、边框 #DCE0E7，采用中性灰白层级。正文 #252934，辅助文字 #616877。
- 按钮、选中、焦点和编辑器选区使用蓝色 #3D5FAD；浅色装饰和阴影不再带绿，首页无背景光晕，装饰色卡使用蓝、紫和沙色。
- 成功状态使用独立绿色 #287746；业务颜色、用户图片和颜色工具实际输出不随主题替换。

## 深色主题

- **中性层级**：页面背景 `#141518`，面板 `#1C1E22`，浮层 `#25282E`，输入区 `#181A1E`；边框 `#34373E`。卡片、编辑器、项目中心及弹窗共用这一层级，文字与背景不再带绿。
- **文字与交互**：正文 `#E8E9ED`，辅助文字 `#ACAFB9`，次级标注 `#9398A5`；按钮、选中、键盘焦点和编辑器选区使用雾蓝 `#A6B8F4`，按钮前景 `#171D30`。强调色用于局部交互，不铺满大块背景。
- **状态语义**：成功及差异新增使用绿色 `#8AC5A0`，待更新使用琥珀色 `#E2BB7F`，错误及差异删除使用柔红色 `#EFA0AB`；处理中使用雾蓝。文字、图标和状态说明共同表达含义。成功状态与操作强调色分别维护，避免主题变更改变状态语义。
- **装饰与编辑器**：深色首页不叠加 Aurora 或背景绿色光晕，配色入口使用雾蓝、淡紫和沙色示意。代码行号、当前行、选区、语法高亮、查找浮层同步适配。颜色工具内用户选取的颜色、图片及实际配色数据保持原样。
- **主题切换**：设置支持浅色、深色及跟随系统；项目中心网页与桌面共用主题样式。两种模式分别管理主题变量，共用页面结构与偏好存储格式。

## 布局与交互

- **固定分类导航**：7 个分类按注册表顺序固定排列，整行可点击，最小高度 44px、文字 13px，配图标和工具数量。当前工具所属分类高亮，展开分类有独立边框；打开工具列表不会推移其他分类。桌面端点击分类打开约 320px 宽的非模态浮层，工具显示名称、两行用途摘要与已打开任务数，列表超出可用高度时滚动；选择工具自动关闭面板并复用已有任务。收起侧栏只显示 7 个分类图标。
- **分类键盘与关闭**：再次点击同一分类、点击外部或按 `Esc` 关闭；关闭按钮、`Esc` 和左方向键返回分类焦点。打开时聚焦当前工具或首个工具，上下方向键与 Home / End 移动焦点，Enter 打开；Tab 可离开浮层，不锁住桌面主内容。全局搜索和侧栏模式切换会关闭分类面板。窄屏保留现有模态导航抽屉，进入工具列表后将主要高度让给工具选择；“返回工具分类”或第一次 Esc 返回分类与其他导航入口，再次 Esc 关闭抽屉。
- **首页 Bento 布局**：浅色主视觉使用浅灰蓝面板，深色使用中性面板，两种模式均不叠加 Aurora 光晕；探索按钮聚焦工具库搜索。快捷区打开 JSON、差异对比、时间戳及 UUID 工具，配色卡打开调色板。内容识别保持主动操作。
- **分段切换**：工具库支持全部工具、常用收藏、最近使用，以及卡片 / 列表切换；项目中心共用视图切换组件。左右方向键、Home / End 可在分段选项间切换，按钮提供明确的选中状态与焦点。
- **类别 Marquee**：循环展示注册表中的真实分类与工具数量；悬停、键盘聚焦时暂停，也可通过播放 / 暂停按钮控制。类别筛选仍由下方静态按钮完成。
- **加载与动画**：编辑器模块和项目数据等待期间显示 Skeleton，不增加人为延迟。页面、弹窗、卡片与分段指示器使用短过渡；Aurora 入场后停稳。系统启用 `prefers-reduced-motion` 时关闭动画、循环和自动平滑滚动。
- **响应式**：小屏幕下侧栏变为抽屉，Bento 单列排列；快捷工具保留一排，搜索和分段控件适应可用宽度。项目卡片继续采用紧凑布局。

Nginx 配置与项目中心同级，名称、分类、说明来自 `src/catalog.ts` 的工作台模块注册表。无实例时明确显示“尚未添加 Nginx 实例”，解释Windows/Linux均可一主多附属，并直接提供新建/导入入口。添加实例表单使用统一表面、图标标题、分组字段和固定操作栏，仅内容区域滚动，检测详情按需展开。实例列表展示主文件与运行状态，右侧提供文件页签、默认字段配置、完整源码、备份及命令反馈。字段分组沿用原文 http/server/location 层级，保留自定义指令；宽屏左右分栏，窄屏实例列表置顶。运行操作仅在桌面本机提供，规则见 [Nginx 配置说明](nginx.md)。

未保存确认由 `Confirmation.tsx` / `confirmation.css` 提供单一主题层，表单放弃与应用关闭/重新加载共享此层，不叠加系统消息框和底部警告。确认框提供标题、说明、取消及明确的放弃动作，默认焦点在“继续编辑”，Esc取消，原生dialog约束焦点并在关闭后返回。主进程只在用户确认退出后关闭服务和存储，取消退出仍可继续编辑、保存与执行操作。

窗口关闭按钮默认先展示主题选择框，提供“退出软件 / 最小化到托盘 / 取消”和“记住我的选择”。默认聚焦取消，Esc不退出；选择托盘不触发草稿放弃确认，并保留窗口、请求及项目共享。托盘点击或菜单“打开 DevKit”恢复窗口；“退出 DevKit”绕过托盘偏好，仍触发已有草稿保护。选择退出但取消草稿放弃时不保存退出偏好。主进程将确认后的偏好原子写入 Electron 用户数据目录 `desktop-settings.json`，设置中的“窗口与托盘”可选择每次询问、托盘或退出；此项独立于设置导入导出与“恢复默认偏好”。托盘创建失败保持窗口可见并允许重新选择；Linux托盘可见性依赖桌面环境的 StatusNotifierItem / GtkStatusIcon 支持。

HTTP调试采用方法/地址、参数/请求头/鉴权/正文分区编辑；响应支持格式化/原文与重复头筛选，左侧集合搜索和仅内存会话历史便于复用。保留现有JSON源码模式、集合脱敏及取消/超时行为；正文按原始文本跨度更新，避免编辑无关字段时丢失大整数。具体规则见 [HTTP 调试说明](http-workbench.md)。

Nginx仅在实例输入字段和配置参数旁提供“？”；移除所有操作问号、操作说明汇总和配置块标题的重复问号。字段说明在悬停、点击或键盘聚焦时通过原生popover展示，点击外部或Esc关闭，平时不占字段下方空间。示例不替换原值；路径提示展示当前基准目录，附属文件解释公共规则的影响范围。同名指令按HTTP/stream/upstream层级解释，未知模块保留通用语法说明。输入项通过aria-describedby关联提示，浮层沿用主题并限制在视口内，在弹窗内部也可操作；Esc只关闭提示，不触发下层表单的关闭确认。

实例列表将选择和删除拆成独立按钮，卡片内显示“删除”，顶部显示完整的“删除实例”；不把删除入口隐藏为取消登记图标，也不因草稿而禁用。主题确认框明确保留文件/备份和运行进程，并在删除当前草稿时说明放弃范围；删除其他实例保留编辑现场，当前项删除后切换相邻项，最终清空回到空状态。

Nginx实例操作区使用NginxControlDock在工作区内吸顶，包含实例信息、运行操作和命令反馈；正文继续自然滚动。吸顶时以约220ms缓动收紧辅助信息并增加轻阴影，可展开详情，执行结果保持可展开摘要且内容高度有界。ResizeObserver维护滚动留白，避免定位字段时被固定区域遮挡；窄屏操作分组横向可达，减少动态效果时关闭动画。自动目录准备结果沿用命令反馈展示，不增加确认弹窗。

样式入口为 `src/theme.css`，统一桌面和网页的层叠顺序；主题变量集中在最先导入的 `src/theme-tokens.css`，组件文件不重复声明全局配色。视觉规则与深色装饰适配位于 `src/design.css`，固定分类及浮层位于 `CategoryNavigation.tsx` / `category-navigation.css`。工作台、首页和共享组件分别位于 `App.tsx`、`Overview.tsx`、`SegmentedControl.tsx`、`Skeleton.tsx`；Nginx 工作区位于 `NginxCenter.tsx` / `nginx.css`。界面使用本地资源，不请求远程字体。

构建后可用 `node scripts/smoke-desktop.mjs --design-only` 单独验证深浅主题、五档宽度、导航与快捷入口、分段筛选、键盘和减少动态效果设置，截图与几何检查记录保存在 `artifacts/electron-smoke/design-*`。`npm run test:electron` 会同时运行这些检查和完整功能回归。
