# 工作空间视觉与交互

弹窗、导航、折叠、HTTP 状态、列表、颜色、拖入和骨架等 16 项过渡共用 `Motion.tsx`、`motion-primitives.ts` 与 `motion.css`。退场保留节点，胶囊按真实尺寸弹簧移动，模式切换保留编辑器，复制与异步反馈由实际结果驱动；具体覆盖、技能规范与兼容性见 [界面动效说明](ui-motion.md)。

工作台浅色模式采用灰白与蓝色，深色模式采用「深灰蓝 + 雾蓝」。两种模式共用本地字体、Lucide 图标、布局与交互。侧栏和顶部操作栏悬浮于页面背景之上，侧栏切换共享栏目，收起侧栏时顶栏提供同名入口。工具任务继续保存在多任务工作区中。

工具和共享栏目的内部界面用标题面板、操作区和内容区建立层次。编辑器的输入、结果和底部状态条采用同一组表面与字号，保留每种工具自己的工作流。项目档案、Nginx 实例、HTTP 接口、请求集合和日志来源使用边缘标记显示选中项。JAR 表格、日志窗、监控曲线和 SSH 会话以可读的数字、细分隔线和有含义的状态色组织操作。视觉流程参考 Damir Sokolovsky 的 [Unslop（CC BY 4.0）](https://heydamir.design/unslop)。

滚动区域采用透明轨道，滑块沿用主题的次要文字色，悬停与拖动时逐步转为强调色。桌面、共享门户和独立快传页共用 `shared/scrollbars.css`，文件共享目录页嵌入同一份样式。SSH 终端将相同的配色应用到自己的滚动控件。在系统强制颜色模式下，原生滚动条由系统绘制。

## 局域网协作工具

快传将文件名或文字正文放在收件条目的第一行，发送人、大小和到期时间列在下一行。宽屏同时呈现发送和接收，窄屏切换收发视图，已选文件和输入草稿会保留。模拟服务使用接口目录、场景选择和语法编辑器，路径、状态码及调用时间使用等宽字体。白板将绘图工具贴在画布边缘，颜色与线宽位于画布下方，画板库和管理操作按需展开。三页均沿用工作台的本地中文字体、主题配色和焦点样式。

## 工作台总览

总览首屏以内容识别为主入口，浅色使用白色输入面板，深色使用深灰蓝输入面板，其他主题沿用各自的颜色和材质。粘贴文本会立即推荐工具，手动编辑后可点击「识别内容」。打开推荐工具会带入原文。输入区下方显示最多三个常用工具，有打开的任务时优先显示「继续工作」。

首屏使用本地静态光带。极简扁平、新野兽派和性能模式采用各自底色。

首屏隐藏滚动条。向下滚动、向上滑动手指或点击「浏览工具库」，工作区整屏切换到工具库。工具库可独立滚动，顶部保留搜索、卡片／列表切换和回到总览按钮。滚至工具库顶部后再次向上滚动可返回总览，按 `/` 则直接进入工具库并聚焦搜索。分类、收藏和最近使用由侧栏承载。系统启用减少动态效果时直接切换。样式位于 `src/overview.css`。

## 主题风格

设置中的“主题风格”与“明暗模式”分别保存。默认主题采用雾蓝与深灰蓝，其他风格包括极简扁平（黑白与小圆角）、自然有机（暖米色与森林绿）、编辑杂志（纸张色、酒红与本地衬线标题）、新野兽派（紫色、粗边框与硬阴影）；另有柔和界面（藕紫、圆润面板与柔软阴影）、macOS 毛玻璃（冷灰层次与半透明模糊表面）、现代渐变（紫蓝渐变与通透光影）、复古怀旧（奶油纸色、铜橙与衬线标题），共九套。每套都适配浅色、深色、跟随系统。共享网页顶部提供相同风格选择，偏好仅保存在当前浏览器，不修改主机设置；旧设置与无效风格回退默认，设置导入导出包含风格。

桌面端「偏好设置」底部的「关于 DevKit」从项目元数据读取当前版本、作者、联系邮箱和 GitHub 地址。「复制邮箱」显示剪贴板反馈，GitHub 图标和地址通过同一个链接在系统默认浏览器打开仓库。

风格参考 [StyleKit 风格库](https://www.stylekit.top/zh/styles)，自行实现，不复制模板代码。实现对比 [daisyUI](https://github.com/saadeghi/daisyui) 和 [shadcn/ui](https://github.com/shadcn-ui/ui) 的语义变量主题设计；继续使用现有组件，无新增依赖或远程字体。`src/themes.ts` 为风格注册表，`src/theme-styles.css` 在统一样式入口末尾覆盖语义变量及组件表现，`data-theme-style` 与原有 `data-theme` 独立。

项目中心批量操作栏统一使用Lucide图标与文字：启用、停用、删除、检测、复制、清除选择均保持相同图标尺寸和 6px 间距。选中项目后出现批量操作栏，窄屏按整个按钮换行。

## 字体与选择控件

界面使用本地中文无衬线字体。代码依次查找 Cascadia Mono、SFMono-Regular、Menlo、Consolas 和 Linux 系统等宽字体，中文回退到思源等宽、微软雅黑或苹方。代码默认 14 px、1.7 倍行高，关闭连字。已有字号偏好继续生效。纯文本恢复模式和结果区共用代码字体。

设置中的明暗、密度、缩进、布局和运行模式，以及工具任务中的固定短选项，使用分段控件。Tab 进入当前选项，左右方向键切换，Home 与 End 跳至首尾。启动页面、代码字号和结果发送目标沿用下拉选择。项目中心把启停与配置异常筛选移到同一组按钮中。

## 布局与交互

- **固定分类导航**：7 个分类按注册表顺序固定排列，整行可点击，最小高度 44px、文字 13px，配图标和工具数量。当前工具所属分类高亮，展开分类有独立边框；打开工具列表不会推移其他分类。桌面端点击分类打开约 320px 宽的非模态浮层，通过原生 `popover="manual"` 进入浏览器顶层，避免侧栏的 `backdrop-filter` / transform 改变层叠和固定定位；以视口坐标定位，保留 DOM 键盘顺序和退场动画。窄屏继续使用抽屉内嵌列表。浮层内工具显示名称、两行用途摘要与已打开任务数，列表超出可用高度时滚动；选择工具自动关闭面板并复用已有任务。收起侧栏只显示 7 个分类图标。
- **分类键盘与关闭**：再次点击同一分类、点击外部或按 `Esc` 关闭；关闭按钮、`Esc` 和左方向键返回分类焦点。打开时聚焦当前工具或首个工具，上下方向键与 Home / End 移动焦点，Enter 打开；Tab 可离开浮层，不锁住桌面主内容。全局搜索和侧栏模式切换会关闭分类面板。窄屏保留现有模态导航抽屉，进入工具列表后将主要高度让给工具选择；“返回工具分类”或第一次 Esc 返回分类与其他导航入口，再次 Esc 关闭抽屉。
- **共享栏目导航**。从侧栏“共享栏目”打开列表和排序，收起侧栏时可从顶栏同名入口访问。拖动左侧手柄时可预览落点，靠近列表边缘可继续滚动。也可直接选择目标位置，或用上下箭头微调。移动后焦点留在栏目的操作控件上，读屏会提示新位置。拖动时按 Esc 取消拖动，退出弹窗会丢弃本次未保存的修改。“保存顺序”即时更新两个入口并保存到本机，也可先恢复默认顺序再保存。设置备份包含栏目顺序，新增栏目排在已排序栏目的末尾。
- **首页**。优先显示继续任务、内容识别、常用工具和工具库。常用工具优先显示收藏，顶栏搜索可用 Ctrl/⌘+K 打开。
- **分段切换**：工具库支持全部工具、常用收藏、最近使用，以及卡片 / 列表切换；项目中心共用视图切换组件。左右方向键、Home / End 可在分段选项间切换，按钮提供明确的选中状态与焦点。
- **加载与动画**：编辑器模块和项目数据等待期间显示 Skeleton，不增加人为延迟。页面、弹窗、卡片与分段指示器使用短过渡；系统启用 `prefers-reduced-motion` 时关闭动画、循环和自动平滑滚动。
- **响应式**：小屏幕下侧栏变为抽屉，启动面板纵向排列；搜索和分段控件适应可用宽度。项目卡片继续采用紧凑布局。

Nginx 配置与项目中心同级，名称、分类、说明来自 `src/catalog.ts` 的工作台模块注册表。无实例时明确显示“尚未添加 Nginx 实例”，解释Windows/Linux均可一主多附属，并直接提供新建/导入入口。添加实例表单使用统一表面、图标标题、分组字段和固定操作栏，仅内容区域滚动，检测详情按需展开。实例列表展示主文件与运行状态，右侧提供文件页签、默认字段配置、完整源码、备份及命令反馈。字段分组沿用原文 http/server/location 层级，保留自定义指令；宽屏左右分栏，窄屏实例列表置顶。运行操作可在桌面本机及明确授权的共享页面提供，规则见 [Nginx 配置说明](nginx.md)。

未保存确认由 `Confirmation.tsx` / `confirmation.css` 提供单一主题层，表单放弃与应用关闭/重新加载共享此层，不叠加系统消息框和底部警告。确认框提供标题、说明、取消及明确的放弃动作，默认焦点在“继续编辑”，Esc取消，原生dialog约束焦点并在关闭后返回。主进程只在用户确认退出后关闭服务和存储，取消退出仍可继续编辑、保存与执行操作。

窗口关闭按钮默认先展示主题选择框，提供“退出软件 / 最小化到托盘 / 取消”和“记住我的选择”。默认聚焦取消，Esc不退出；选择托盘不触发草稿放弃确认，并保留窗口、请求及项目共享。托盘点击或菜单“打开 DevKit”恢复窗口；“退出 DevKit”绕过托盘偏好，仍触发已有草稿保护。选择退出但取消草稿放弃时不保存退出偏好。主进程将确认后的偏好原子写入 Electron 用户数据目录 `desktop-settings.json`，设置中的“窗口与托盘”可选择每次询问、托盘或退出；此项独立于设置导入导出与“恢复默认偏好”。托盘创建失败保持窗口可见并允许重新选择；Linux托盘可见性依赖桌面环境的 StatusNotifierItem / GtkStatusIcon 支持。

HTTP调试采用方法/地址、参数/请求头/鉴权/正文分区编辑；响应支持格式化/原文与重复头筛选，左侧集合搜索和仅内存会话历史便于复用。保留现有JSON源码模式、集合脱敏及取消/超时行为；正文按原始文本跨度更新，避免编辑无关字段时丢失大整数。具体规则见 [HTTP 调试说明](http-workbench.md)。

Nginx仅在实例输入字段和配置参数旁提供“？”；移除所有操作问号、操作说明汇总和配置块标题的重复问号。字段说明在悬停、点击或键盘聚焦时通过原生popover展示，点击外部或Esc关闭，平时不占字段下方空间。示例不替换原值；路径提示展示当前基准目录，附属文件解释公共规则的影响范围。同名指令按HTTP/stream/upstream层级解释，未知模块保留通用语法说明。输入项通过aria-describedby关联提示，浮层沿用主题并限制在视口内，在弹窗内部也可操作；Esc只关闭提示，不触发下层表单的关闭确认。

实例列表将选择和删除拆成独立按钮，卡片内显示“删除”，顶部显示完整的“删除实例”；不把删除入口隐藏为取消登记图标，也不因草稿而禁用。主题确认框明确保留文件/备份和运行进程，并在删除当前草稿时说明放弃范围；删除其他实例保留编辑现场，当前项删除后切换相邻项，最终清空回到空状态。

Nginx 实例操作区使用 `NginxControlDock`。吸顶后只保留检查配置、启动、重载、停止和保存文件五个按钮，实例信息、其他操作和执行详情在约 140ms 内收起。滚回顶部显示完整内容。ResizeObserver 按实际操作栏高度维护滚动留白，避免遮挡字段定位。窄屏保持单行，减少动态效果时关闭过渡。

样式入口 `src/theme.css` 统一桌面和网页的层叠顺序，配色变量位于 `src/theme-tokens.css`。`src/design.css` 管理应用外观，`src/workspace-surfaces.css` 管理工具与各模块的内部界面，固定分类及浮层位于 `CategoryNavigation.tsx` 和 `category-navigation.css`。界面使用本地资源。

构建后可用 `node scripts/smoke-desktop.mjs --design-only` 单独验证深浅主题、五档宽度、导航与快捷入口、分段筛选、键盘和减少动态效果设置，截图与几何检查记录保存在 `artifacts/electron-smoke/design-*`。`npm run test:electron` 会同时运行这些检查和完整功能回归。


局域网共享属于应用级服务：顶部工具栏保留统一入口与开启/关闭/读取失败状态，运行时以状态点和文字反馈，窄屏缩为带状态点的地球图标并保留可访问名称。项目中心、Nginx、HTTP 使用同一Provider的快捷入口，设置面板与模块草稿独立；轮询和回到窗口会刷新运行状态，不覆盖正在填写的表单。统一管理地址/口令/开放模块/编辑和Nginx运行权限，沿用草稿关闭保护与主机API。实现位于Sharing.tsx和sharing.css。

共享门户的主题和退出登录仅放在顶部全局栏；各模块只承载自己的操作。三个共享服务各自有开放开关和紧随其后的权限，关闭服务清除授权，编辑与执行互不绑定。全局快捷键在任意原生模态弹窗打开时不触发后台任务。具体审查及回归见 [交互一致性审查](interaction-audit.md)。

共享网页布局独立于桌面main规则，门户导航外置于主滚动区。HTTP正文使用主滚动，宽屏目录可独立滚动，窄屏纵向排列；Nginx吸顶基于实际主滚动根。三服务hash入口保留浏览器历史和滚动位置；共享定义、本次调试和访客本地数据的文案分别表达。完整修复清单见 [共享网页版说明](portal-browser.md)。

分类浮层专项回归：构建后运行 `node scripts/smoke-desktop.mjs --navigation-only`，覆盖九套主题的深浅模式、顶层状态、四角/中心实际命中、固定定位，以及键盘、收起侧栏、短窗口和窄屏抽屉流程。


## 工具和共享栏目
