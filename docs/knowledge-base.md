# 团队知识库

在桌面或局域网共享网页打开「共享栏目 → 团队知识库」。选择「新建文档」，填写标题和所属项目，选择部署手册、故障排查或项目交接模板。项目名可直接填写，也可沿用已有名称；留空归入通用。Markdown 支持标题、列表、表格、代码块及链接，可先预览再保存。

## 部署步骤与实例联动

1. 在正文中将光标放在需要引用资源的步骤，例如“验证应用健康状态”。
2. 在「插入资源链接」中选择「JAR 实例」或「Nginx 实例」，再选择具体实例。链接指向该主机上的实例标识。可在一篇手册中引用多个本机或远程实例，也可直接撰写纯文本步骤。其他可选资源包括项目入口、接口、局域网主机和监控项。
3. 保存后点击步骤内的链接打开目标。JAR 管理和 Nginx 配置沿用各自的查看、编辑与运行权限，执行操作仍需在对应栏目中进行。
4. 在 JAR 实例或 Nginx 实例详情中点击「关联手册」，可查看当前正文引用它的文档。从此处新建文档会预填该实例的引用。复制代码块中的链接示例不会将示例计为引用。

## 查找、共享与恢复

在目录中按项目、类型筛选，或搜索标题和正文。点击「复制链接」获得按文档 ID 定位的固定链接；要发给同事，请先开启局域网共享并授权知识库。重命名文档后链接仍有效。

共享设置中可独立开放知识库，默认关闭。获得查看权限的访客可以阅读**全部文档及其历史版本**，正文中作者填写的资源名称也会随文档共享。编辑权限允许访客创建、修改、恢复、删除文档。访客只能从已开放的目标栏目选择资源，未授权的跳转会在当前页面给出提示。

每次保存都会记录版本。打开「版本历史」可预览最近 20 个旧版本，恢复会写成新的当前版本。两人同时编辑时，后提交的草稿会保留在编辑窗口并提示冲突；可复制草稿、关闭后重开最新版本再合并。删除文档将同时删除其历史。

主机在 `configs/knowledge.json` 保存全部文档与版本。单篇正文上限 12 万字符，整个知识库上限 32 MiB。关闭桌面或独立服务后可随配置目录一起备份、迁移。独立 Node 服务通过 `DEVKIT_SHARE_KNOWLEDGE=true` 开放阅读，通过 `DEVKIT_KNOWLEDGE_EDIT=true` 允许编辑，独立访客仍受自身授权约束。
