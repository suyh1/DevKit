# 团队知识库

在「共享栏目 → 团队知识库」点击「新建文档」进入独立写作页。普通文档从空白开始，填写标题和正文就能保存。需要提纲时可在「从模板新建」选择部署手册、故障排查或项目交接。模板只预填正文，所有文档使用相同的编辑器。

## 整理与写作

在目录选择框旁点击「新建目录」，用斜杠建立多级目录，例如「基础知识/网络」。选中某目录时新文档会继承它，选择父目录可以同时浏览其子目录。打开「文档属性」可以修改目录、项目和标签。目录留空归入「未归档」。原有文档及其历史版本保留原标识，升级时旧类型成为标签。

Markdown 编辑支持语法高亮、列表续行和常见配置代码块高亮。选中文字按 Ctrl/Cmd+B、I、E 可添加粗体、斜体和行内代码。宽屏可选「编辑」「分栏」或「预览」；窄屏在编辑与预览之间切换，返回时可从原处继续输入。

修改自动写入当前设备和当前浏览器用户的本机草稿。点击「知识库」离开后，从「本机草稿」继续写作。刷新后仍可恢复。Ctrl/Cmd+S 或「保存」将修改提交到主机并留在写作页，「完成编辑」保存并返回阅读。需要放弃未提交的修改时可选「丢弃草稿」。设备存储不可用时请查看提示并手动保存到主机。草稿不会跨设备同步。

## 批量插入资源

1. 将光标放在需要引用的位置，打开「插入资源」。
2. 勾选一个或多个栏目，可在知识库文档、JAR、Nginx、监控、项目、接口、主机之间组合。按名称或主机搜索，切换筛选会保留已选项，点击已选条目可以移除。
3. 确认「插入 N 项」。一项作为行内链接，多项按勾选顺序插入 Markdown 列表。取消不改变正文。
4. 阅读时点击链接打开对应资源，相关操作沿用目标栏目权限。从 JAR 或 Nginx 的「关联手册」入口新建，会预填实际实例名、所属主机及链接。知识库文档可互相引用，阅读页底部列出引用本文的文档。代码示例中的链接不计入反向引用。

## 查找、共享与版本

正文搜索结果显示命中片段，点击可定位到相应段落。展开「本文目录」可跳转到标题或复制章节链接。同名标题按出现次序区分，重命名标题会改变章节链接。文档固定链接随文档改名仍有效。请先在共享设置中开放知识库并授权，再向同事分享地址。

知识库默认关闭。查看权限允许阅读全部文档和历史版本，编辑权限可创建目录、编辑、恢复和删除文档。访问其他栏目单独授权。主机保留最近 20 个旧版本，恢复会生成新的当前版本。并发编辑发生冲突时可以对照主机版本修改草稿，基于此版本保存或另存副本。

主机在 `configs/knowledge.json` 保存文档、目录和历史版本。单篇正文最多 12 万字符，整个知识库上限 32 MiB。关闭服务后可随配置目录一起备份、迁移。独立服务通过 `DEVKIT_SHARE_KNOWLEDGE=true` 开放阅读，通过 `DEVKIT_KNOWLEDGE_EDIT=true` 开放编辑，独立访客仍受自身授权约束。
