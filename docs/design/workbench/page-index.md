# DevKit PC 逐页设计与验收

142 张静态画板。每个注册入口都有独立画板；全局与专项流程按任务补充。下表的页码按 PDF 实际页序计算。如果阅读器忽略页码链接，可使用文件内目录或书签。上方导航、底部动作、主题、缩放与键盘约定见[整机设计方案](README.md)。

## 组件定位

表格检查复用 AnalysisTable 与既有查看器；时间图、火焰图和排名使用现有分析可视化入口。代码编辑、文件读入、颜色与二维码各走现有工作区。表中“操作与验收重点”是拟议的页面呈现，执行条件、读写权限和业务结果由现有工具及服务提供。[通用组件与工作区映射](README.md#现有组件如何接入)
