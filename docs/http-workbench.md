# HTTP/API 工作台

在桌面端的侧栏或顶部导航打开“HTTP 调试”。它与离线的“HTTP 请求代码生成”分开：代码生成器不联网；调试工作台只有点击“发送请求”才从当前桌面或共享主机访问目标。

桌面顶部“局域网共享”和本页“共享设置”打开同一全局面板，统一管理开放模块、访客编辑及主机运行权限。

## 接口项目：设计、文档与调试

默认打开“接口项目 · 文档与调试”。项目和接口互相独立，目录可分组并通过名称、HTTP方法或路径搜索。通过“新建API项目”填写名称、默认服务地址及说明，在项目设置中添加目录和多个环境；环境有自己的服务地址和变量，可逐项启停。目录重命名同步更新所属接口，移除目录将接口移到“未分组”。

每个接口有三个原生视图，共用一份定义：

- **接口设计**：编辑名称、目录、HTTP方法、路径和说明，定义Path/Query/Header/Cookie参数的位置、类型、必填、启停、说明和示例；维护无鉴权、Bearer、Basic或Header/Query API Key，及JSON、文本或URL Encoded正文。请求和响应支持JSON Schema与示例，可从JSON示例生成结构后自行调整约束。不同响应可用精确状态、2XX等范围或default区分。
- **接口文档**：即时显示接口说明、服务地址、鉴权方式、参数表、正文和响应示例；Schema按字段表呈现类型、必填及说明，支持展开原始Schema。循环引用明确标记，结构表最多500行/16层，完整Schema仍保留。文档使用纯文本和代码编辑器展示，不执行HTML或脚本。
- **运行调试**：选当前环境，编辑参数值、鉴权和正文，查看最终请求配置再主动发送。缺少变量、未填必填参数、参数类型错误、重复鉴权头或无效Schema语法会阻止发送。响应展示正文、完整重复头、耗时和大小，支持格式化、筛选、复制和导出。HTTP错误响应也保留供检查；实际JSON响应可“采用为响应示例”，确认保存接口后更新文档。

路径应以 / 开头，如 /users/{id}；Path参数按值编码，Query保留重复项与空字符串。Query数组用重复键，对象按键值展开；Path/Header数组和对象采用simple序列化，Cookie采用form非explode序列化。服务地址来自接口独立地址、当前环境或项目默认地址；Query及锚点应放在参数定义中。

变量语法为 {{变量名}}，可用于参数值、鉴权和正文；变量名使用字母、数字和下划线，且不能以数字开头。内置baseUrl来自当前环境/项目，启用的环境变量可覆盖。变量不递归展开。JSON正文只在字符串中替换变量，并正确转义引号和换行，保留原始数字；URL Encoded正文按键值替换后编码，避免变量中的 & 或 = 改变参数结构。

### 本地响应校验

先匹配精确状态码，再匹配范围，最后使用default；分别检查状态、Content-Type和JSON Schema。支持媒体类型通配符。Schema校验在独立Worker中运行，先用随应用附带的官方2020-12 meta-schema检查定义，再验证正文；无eval、无动态脚本，不需要网络。

未定义Schema、二进制正文、超时、校验器异常或不支持的动态引用均明确显示“未验证”，不会算作通过。超过2秒会终止Worker。JSON中的超大整数或溢出数值保持显示原文，但数值精度不足时不判定Schema通过；请求正文Schema无法精确验证时会阻止发送，用户可调整契约后重试。当前以2020-12常用验证词汇为目标，不承诺全部方言、扩展或格式断言；动态引用不支持。请求前在同一预算内批量校验已配置的参数及请求正文Schema；参数的必填与基本类型也会在构造请求时检查。

同一次响应采用发送时的定义校验。之后修改定义或环境会标记“上次响应”，避免把旧响应当成新结果。会话历史最多20条、定义合计4MB，仅在内存，点击恢复请求定义及环境选择，不自动发送，不保存响应。

### 文件保存、恢复与导入导出

API项目主动保存到安装目录的 configs/http/api-workspace.json，与项目中心、旧HTTP集合分别管理。最多30项目，每个项目500接口、30环境，每个接口200参数、20响应定义；工作区整体16,000,000字符。保存使用目录锁、串行队列、版本校验、写入同步和临时文件原子替换，失败保留编辑草稿。刷新会保留当前接口草稿供核对，不静默覆盖；关闭/刷新应用或替换未保存接口前有草稿保护。

每次保存保留上次保存前的整个工作区，可通过“恢复上次保存”确认恢复；恢复也保留恢复前的数据。损坏文件报错并保留，不创建空数据替换。整目录迁移时关闭两边应用再复制configs。文件会包含正文、鉴权及环境变量的明文，应按实际内容保管。

导入先校验并预览接口、目录、环境数量及转换警告，确认后作为独立项目加入，保留现有数据：

- 支持OpenAPI 3.0/3.1、Swagger 2.0的JSON/YAML，解析本地引用并打包循环Schema，支持OpenAPI服务器变量默认值。远程/跨文件引用明确拒绝，需先将规范打包成单文件，运行时不会自动下载。
- 支持基础Postman v2请求集合转换及旧DevKit请求集合迁入。含继承变量/鉴权、文件/GraphQL正文等暂不支持的结构会拒绝并说明原因；脚本不导入且不执行。此入口覆盖基础请求，不承诺Postman所有扩展。旧集合已排除的鉴权/正文无法恢复，原记录不会删除。
- 多媒体类型或多种可选鉴权等需要取舍的情况会在预览列出警告；同时需要多种鉴权等无法可靠转换的内容明确拒绝。OAuth2/OpenID可映射为手动提供accessToken的Bearer鉴权，不执行授权或登录流程。
- 导出OpenAPI 3.1或离线可读的Markdown文档；环境变量和专用鉴权配置中的凭据不会带出，但参数/正文/示例按定义导出，仍可能含用户主动填写的敏感内容。JSON OpenAPI示例保留大整数和数字原文。原生项目备份完整包含环境、正文和鉴权值，导出前会明确确认。

普通HTTP接口设计、文档和调试工作流已覆盖；暂不包含文件上传、HTTP/2、gRPC、WebSocket、脚本运行器、OAuth交互授权、Cookie jar、自动重定向和团队云同步。离线指功能、界面、校验器和数据均不依赖互联网；实际请求仍需目标服务可达，可以是本机或内网服务。

## 快速请求：编辑与发送

表单与配置 JSON 切换保留编辑器实例；发送按钮原地切换为取消。等待、错误与响应区域使用高度过渡，响应到达立即展示；减少动态效果时直接切换。复制反馈取决于实际剪贴板写入结果。

请求表单支持方法/URL、参数表、请求头、鉴权和正文；“配置 JSON”可编辑完整配置。支持 GET、HEAD、POST、PUT、PATCH、DELETE、OPTIONS；仅 HTTP(S)，URL 不支持内嵌用户名/密码。示例：

```json
{
  "method": "POST",
  "url": "http://127.0.0.1:9000/api/users",
  "headers": { "Content-Type": "application/json" },
  "body": { "name": "张三", "active": true }
}
```

body 可为文本字符串或 JSON 值。结构化 body 按原始 JSON 数字/字段原文发送，未指定 Content-Type 时补 application/json；GET/HEAD 不支持非空请求体。重复配置字段、重复请求头名称（忽略大小写）会报错。

- **参数 / 请求头**：逐行添加、删除与启停；参数与 URL 双向同步，保留重复参数名、空值并自动编码。禁用行保留在当前表单内存，不发送、不保存到配置；切换集合、恢复历史或重新载入表单后按实际配置重建。
- **鉴权**：支持 Bearer Token 与 Basic Auth，点击“应用到请求头”显式设置 Authorization；“无鉴权”应用后移除该头。已有头可直接在请求头中修改，鉴权输入框不从头中反解密码。Basic 使用 UTF-8，用户名不允许冒号。
- **正文**：支持 JSON、纯文本与 application/x-www-form-urlencoded 表单，选择类型并编辑时同步 Content-Type；自定义 Content-Type 可随后在请求头中修改。JSON 编辑保留大整数、指数及重复 body 字段原文；不完整 JSON 按原文发送，可用于接口校验测试。“清空正文”可用于切换 GET/HEAD。

点击发送后可随时取消；超时覆盖 DNS、连接、响应读取及解压全过程，默认 15,000ms，可设 100–120,000ms。显示状态码、耗时、正文、完整响应头（保留重复头），支持复制和导出。HTTP 4xx/5xx 作为正常收到的响应展示；网络/TLS/超时错误另行显示。修改配置后保留上次响应并标注待更新。

响应正文可切换格式化 / 原始视图；格式化 JSON 保留数字与重复字段，非 JSON、二进制或超过 1,000,000 字符时直接显示原文。使用编辑器 Ctrl/Cmd + F 搜索正文。响应头以表格展示并可按名称/值筛选，复制和导出采用当前显示的正文或筛选后的头。

左侧集合支持搜索；“会话历史”保留最近 20 次成功、失败或取消的请求，配置总计最多 4,000,000 字符，仅留在内存，不保存响应。点击历史项恢复当时的请求配置及超时，不自动发送；替换未保存草稿仍需确认。历史中可包含鉴权和正文，刷新/退出或“清空历史”后清除；保存集合时继续遵循下方脱敏选项。

请求由 Electron 主进程的受限客户端发出，不受网页 CORS 限制，不使用 shell/cURL，不修改页面 CSP 或关闭 TLS 验证。不会自动跟随 3xx，避免无意把认证数据带往其他目标。客户端不维护 Cookie jar、不读浏览器 Cookie；需要 Cookie 时在请求头中显式填写。HTTPS 使用 Node 默认 CA，不提供“忽略证书错误”开关。

请求正文最多 2MB；请求头最多 100 项、64KB。Content-Length、Connection、Transfer-Encoding、Upgrade、Expect、Proxy-Connection 由客户端管理。响应原始载荷与解压后各最多 4MB；支持 gzip/deflate/br。文本按 Content-Type charset 解码，二进制、未知编码或无效文本以 Base64 展示。HTML 只作为文本，不渲染页面或执行脚本。最多允许 4 个后台并发请求，当前界面逐次发送。

## 请求集合与敏感信息

- 请求草稿、会话历史和响应默认只在内存；切换工作台模块或最小化到托盘时保留，真正退出/刷新时有未保存草稿或运行中请求会提示。
- “保存请求”主动写入当前桌面用户的本地存储，最多 100 项、4MB；与项目中心 configs、文本工作区快照分别管理。
- 默认排除 Authorization/Cookie 及常见 token/password/secret/api-key/signature/session/credential 请求头和 Query 参数，并排除整个 body。界面原草稿保留，重新选择集合项才载入保存的版本。
- 这些名称筛选不能识别所有业务自定义敏感字段。勾选“保存时包含完整 Headers、正文与敏感参数（明文）”后会完整保存；集合项会明确标记。保存和导出前请根据实际配置选择。
- 支持删除、JSON 导出及合并导入；导入使用新标识保留原集合，不发送请求。导入前显示确认；损坏的本地集合会提示且不在启动时覆盖。

代码生成器中的“在 HTTP 调试中打开”携带当前配置，不自动发送；调试工作台中的“生成请求代码”打开独立代码任务。桌面共享与独立 Node 服务可显式开放 HTTP 接口项目、文档、环境及真实调试。接口项目共用主机存储；快速请求集合仍存各浏览器本地，响应与历史仅在当前页面内存。参见 [局域网共享工作台](workspace-sharing.md)。

快速请求与接口项目暂不支持文件/multipart 上传、代理设置、HTTP/2/gRPC、自动重定向、Cookie 会话管理或认证脚本。已有 Header/body 可用于常规本地接口联调。

## 验证与参考

`npm run test:http` 使用隔离本地服务验证正文保真、重复响应头、取消/超时、重定向、二进制、压缩与解压预算；`node scripts/smoke-desktop.mjs --http-close-only` 验证参数/请求头/鉴权/正文编辑、真实发送、格式化/重复头筛选、集合脱敏、历史恢复及深浅窄屏，并检查托盘和草稿退出保护。设计参考 [Hoppscotch](https://github.com/hoppscotch/hoppscotch) 与 [Bruno](https://github.com/usebruno/bruno)（均 MIT）；不引入它们的前端/后端，界面采用本项目主题。请求使用 Node 内置 HTTP/HTTPS/zlib；Schema校验器和官方meta-schema均编译到本地Worker，运行时没有CDN、代理或下载依赖。

共享时在 HTTP 服务卡片分别授权“编辑接口项目”和“发送调试请求”，可以只发送而不保存定义，也可只维护定义而禁止从主机发送。请求始终由共享主机执行，localhost 指共享主机；生成请求代码在当前浏览器离线完成，不触发发送。会话失效会保留页面草稿并提供重新登录，退出登录先确认再清除当前会话。详见 [共享工作台](workspace-sharing.md)。

接口运行调试的参数、鉴权、正文和超时仅作为本次请求覆盖值，不修改定义或默认示例；恢复历史也恢复为调试值。“恢复定义值”清除覆盖。定义仍在接口设计中修改；采用响应为示例需显式操作并保存。未保存新接口会显示在左侧草稿区，保存后才进入共享目录。局域网 HTTP 复制有回退及手动窗口，详见 [共享网页版说明](portal-browser.md)。

本次调试值存在覆盖时，切换到其他接口或新建接口会先提示是否放弃这些本页草稿；切换设计/调试视图或共享服务不会丢弃它们。
